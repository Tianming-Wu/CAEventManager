# 名单

名单是可以反复用的一批人：社团成员、某次比赛的选手。名单与活动并列，活动从名单里取人。

入口是「名单与报名 › 我的名单」，新建、导入、打开都从这里走。

## 建一份名单

- **手动新建**：填名称，再往里加人
- **导入**：支持 CSV、TSV 与 xlsx
  - CSV / TSV：第一行可以是表头（学号、姓名、班级、分组、备注）；没有表头按「学号,姓名,班级」读
  - xlsx：只读第一个工作表，第一行当表头；所有单元格按文本读（学号里的前导零不会掉），
    空行跳过，合并单元格只取左上角。公式、图表、多个工作表这些不处理
- 两种导入都按学号增量合并：没有的人新增、已有的人更新资料。导入后报告新增几人、
  名单内已有几人、有几行读不了

## 人员是平台级的

同一个人在多份名单里是同一条人员记录，改一次姓名各处一致。院系与班级分两列存。

## 成员

- **标成「已退出」**：历史留着，人不再算在册
- **移出**：从这份名单里去掉了
- 名单详情里可以按学号、姓名、分组、备注搜，也可以按状态筛

## 可见性

三档：私有（只有创建者）、公开（所有登录账号可看）、组织公开（组织建好之前等同公开）。

## 写权限

看得见与改得动是两件事：

- 公开名单上谁都能「申请写入权限」。申请后是立刻生效还是等拥有者确认，由这份名单自己的设置决定
- 私有名单只能由拥有者按登录名邀请
- 拥有者永远可写，也能随时把人移出；被授予的人改不了「谁能写」，也不能删名单

待处理的申请在「名单与报名 › 写入审批」里批。见 [`approval.md`](approval.md)。
