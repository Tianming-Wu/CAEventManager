# 账号与角色

## 三种角色

| 角色 | 能做什么 |
| --- | --- |
| 站长 | 一台服务一个。除全部管理功能外，还有「服务器管理」「模块管理」「审计日志」 |
| 超级管理员 | 用户管理、活动管理、活跃审批、展示屏幕 |
| 管理员 | 自己的活动、自己的名单与报名、预设、运维助手 |

注册下来是「管理员 · 待审核」，审核通过才变成正式的管理员。

## 登录名

`[0-9A-Za-z_-]`，3～24 位；`admin`、`root`、`owner`、`support` 这类词是保留词，不能注册。
登录名不分大小写地唯一，改一次之后旧的登录名立即失效。

## 账户信息

在侧栏最下面点自己的账号卡片。这里能改称呼、登录名、头像与密码。

- 称呼是别人在成员列表、审计日志里看到的名字；没填就用登录名
- 头像随账号走，换一台设备登录还是它
- 改密码要输一遍当前的密码

## 敏感操作要重新输一次密码

改角色、封禁或停用账号、轮换活动访问地址、存档活动这类动作，会先要一次密码。

输过之后顶栏左侧出现盾形标记，十分钟内不再问；点它可以看到还剩多久，也可以手动退出。
这条记在这次登录上：换一台设备不继承，退出登录立即失效。

## API 令牌

给平台之外的程序用，例如脚本、群机器人。入口也在「账户信息」，一人一张或多张。
怎么建、三档范围、以及它做不到什么，见 [`../reference/api-tokens.md`](../reference/api-tokens.md)。

## 界面设置

主题三档：跟随系统、浅色、深色。跟随系统跟着操作系统的深浅色切换。
