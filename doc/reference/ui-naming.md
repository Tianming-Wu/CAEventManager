# 界面描述写法 - 位置词、按钮与图标

使用文档和运维助手使用下列名称描述界面位置和控件。

## 位置词

| 词 | 指什么 |
| --- | --- |
| 顶栏 | 面板顶部区域，显示产品名称、版本、服务状态和通知入口 |
| 侧栏 | 位于面板左侧的导航区域 |
| 页面标题 | 内容区顶部的标题，例如「我的名单」 |
| 页面副标题 | 标题附近的状态或说明文字 |
| 页面右上角 | 页面标题区的右侧，通常放置主操作 |
| 内容区 | 标题区下方的主要内容区域 |
| 卡片 | 有独立标题栏的内容区域，可在标题栏右侧放置搜索和操作 |
| 表格 | 按行和列展示数据的控件，操作列通常位于右侧 |
| 页签 | 用于切换同一页面内各内容区的控件，例如「操作台」和「日志」 |
| 抽屉 | 从页面侧边展开的面板，例如会话列表 |
| 弹窗 | 覆盖当前页面的独立操作区域，例如「模型设置」 |
| 输入框 | 用于输入内容的控件 |

## 布局

界面布局按窗口宽度划分：

| 窗口宽度 | 侧栏 |
| --- | --- |
| 大于 1100px | 侧栏带文字 |
| 761～1100px | 侧栏仅显示图标，点击分组后可显示子项 |
| 760px 及以下 | 侧栏默认收起，顶栏左侧出现 [打开导航（三条横线图标）] |

窄屏（760px 及以下）另有几处不同：内容区单列、表格横向滚动（首列与操作列固定）、
日期与时刻改用系统选择器、运维助手的输入框默认显示两行。

写文档时，位置与布局有关的要注明是哪一档，例如：
`宽屏下在侧栏；窄屏下在顶栏左侧的 [打开导航（三条横线图标）] 里`。

## 按钮

- 有文字的按钮写原文，用方括号括起来：[保存]、[导出 Excel]、[移出]
- 只有图标的按钮，在名称后面补图标的样子：[模型设置（齿轮图标）]、[导出这段对话（下载图标）]、
  [新建会话（对话气泡加号图标）]、[全屏编辑（四角图标）]、[更多格式（三个点图标）]、
  [通知（铃铛图标）]、[打开导航（三条横线图标）]、[关闭（叉号图标）]、[返回（左箭头图标）]
- 使用统一的图标名称：齿轮、铃铛、下载、上传、加号、叉号、三个点、左箭头、三条横线、四角、对话气泡
- 写清在哪个区域：`页面右上角的 [模型设置（齿轮图标）]`、`表格最右一列的 [移出]`、
  `输入框右侧的 [发送]`

## 图标

下表列出常用图标的名称和用途。

| 图标 | 用在哪 |
| --- | --- |
| 齿轮 | 用于设置，复用运维助手「模型设置」的齿轮图标 |
| 铅笔 | 重命名、编辑 |
| 复制 | 复制链接、复制文本 |
| 星 | 收藏、保存为预设 |
| 刷新箭头 | 重置、重新生成 |
| 归档箱 | 归档 |
| 垃圾桶 | 删除 |
| 两个循环箭头 | 回收、清理 |
| 加号 | 新建 |
| 三个点 | 更多 |
| 圆里一个感叹号 | 不可用、出错（卡片标题旁的「不可用」胶囊） |

菜单项同时显示图标和文字。仅图标按钮的写法见[按钮](#按钮)。

## 状态与开关

- 开关写「打开 / 关闭」：`卡片标题栏右侧的 [启用] 开关`
- 状态写原文：`状态列的「已退出」`、`标题旁的「待审核」`
- 按钮可用、不可用也要写：`[保存] 在拥有写入权限时才出现`

## 示例

> 报名详情页的页面右上角依次是 [保存设置]、[下载二维码]、[导出报名表]、[导出 Excel]、
> [打印报名表]；[下载二维码] 右边是 [更多格式（三个点图标）]，里面有另外两种图片格式。

## 二次确认的写法

确认提示应说明操作范围、不可逆影响及确认按钮。需要提权时，按 [sudo 模式](../usage/sudo.md)描述实际认证步骤。
