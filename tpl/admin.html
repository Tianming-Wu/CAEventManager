奖票与算法

约等于最快的前 C 人各多一张。建议不超过到场人数的一半。

已发出的奖票不受影响，只要不低于已发张数。

可用：signed_in（已签到参加人员）、present（含工作人员）、 participants、staff_present、tasks_done、guaranteed。 支持 + - * / // % **、括号、min/max/round/abs/int。 每次状态变化都会重算。

0 不看速度，1 首尾 2 倍，2 为 3 倍。
