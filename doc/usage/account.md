# 账号与角色 - 三种身份与账户信息

## 页面结构

「账户信息」一页由三张卡片组成：

- 「个人资料」：页面副标题写「你自己的账号」。卡片里是头像（[更换头像]）、显示名、登录名、
  密码，每处一个 [保存]
- 「API 令牌」：我的令牌列表，副标题「给平台之外的程序使用，例如脚本与群机器人」，
  卡片标题栏右侧 [新建令牌]；每行可吊销
- 「安全」：一个 [退出登录]

「界面设置」一页两张卡片：「主题」里是 [跟随系统] [浅色] [深色]，「其他」里是少量开关。

## 三种角色

| 角色 | 能做什么 |
| --- | --- |
| 站长 | 一台服务一个。除全部管理功能外，还有「服务器管理」「模块管理」「审计日志」 |
| 超级管理员 | 用户管理、活动管理、活跃审批、展示屏幕 |
| 管理员 | 自己的活动、自己的名单与报名、预设、运维助手 |

注册下来是「管理员 · 待审核」，审核通过才变成正式的管理员。

## 登录名

`[0-9A-Za-z_-]`，3～24 位；`admin`、`root`、`owner`、`support` 这类词是保留词，不能注册。
登录名不分大小写地唯一，改一次之后旧的登录名立即失效。

登录名是登录用的凭据，界面上不摆给旁人看：成员列表、邀请成员、活动里的提示只说称呼。

## 账号编号

每个账号还有一个编号，写在「用户管理」里那个账号详情的「编号」一行，形如 `#10001`。
站长是 `#10000`，之后按注册先后往上发，最多到 `4294967295`。

- 编号一次性发放，**发出去就不再回收**：删掉的账号留下的空号不会分给下一个注册的人
- 编号与登录名无关，改登录名、改称呼都不会动它
- 对外说明「是哪一个人」时用编号，不用登录名

## 账户信息

在侧栏最下面点自己的账号卡片。这里能改称呼、登录名、头像与密码。

- 称呼是别人在成员列表、审计日志里看到的名字；没填就显示账号编号，不显示登录名
- 头像随账号走，换一台设备登录还是它
- 改密码要输一遍当前的密码

## 敏感操作要重新输一次密码

改角色、封禁或停用账号、轮换活动访问地址、存档活动这类动作，会先要一次密码。

输过之后顶栏左侧出现盾形标记，十分钟内不再问；点它可以看到还剩多久，也可以手动退出。
这条记在这次登录上：换一台设备不继承，退出登录立即失效。

## API 令牌

给平台之外的程序用，例如脚本、群机器人。入口也在「账户信息」，一人一张或多张。
怎么建、三档范围、以及它做不到什么，见 [../reference/api-tokens.md](../reference/api-tokens.md)。
**三档范围至少要勾一项**：一项都没有的令牌什么也读不到，所以创建键是灰的，
左下角写着「无法创建空权限令牌」。

## 界面设置

主题三档：跟随系统、浅色、深色。
