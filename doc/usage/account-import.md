# 导入账号 - 批量建号与初始密码

几十上百人的时候一个个建号不现实。这一页是给站长用的批量入口：读一张表，检查一遍预览，
再一次性建出来。登录名与初始密码都要手动点 [自动填充] 才补。

## 从哪进去

「用户管理」页面右上角，[新建账号] 左边那颗 [导入账号]。整页全是站长可见——这条路上可以把人
设成超级管理员，所以超级管理员看不到这一颗按钮。

进去之后是「用户管理 › 导入账号」子页，左上角返回键回到用户管理。

## 两种录入方式

- **选文件**：CSV 或 Excel（`.xlsx`）。表头用下面这些列名，中英文都认
- **手动录入**：点 [手动录入] 加一行空的，直接在预览表里填

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 登录名 | 否 | 留空就按姓名拼音自动生成，重名自动加序号 |
| 显示名 | 是 | |
| 角色 | 否 | 管理员（默认）或超级管理员 |
| 初始密码 | 否 | 留空就按下面的规则生成；填了也用填的那一串 |
| 组织 | 否 | 预留：组织功能上线后才会生效 |
| 备注 | 否 | 写进账号备注 |

表里其余列也读进来，写密码规则时能引用（例如学号）。

## 自动填充

导入表只负责"读进来"，**不会替人补任何内容**：登录名与初始密码留空的格子就留着空，
对应那一行标红、不能导入。

要补就点 [自动填充]，弹窗里选这一次补什么：

- **补齐登录名（按姓名拼音）**：只补空的登录名，撞名自动加序号
- **补齐初始密码**：按下面的规则给空的密码生成一串
- **密码规则**（只在勾了「补齐初始密码」时起作用）：

| 选项 | 生成的密码 |
| --- | --- |
| 随机 12 位 | 去掉 0/O/1/l/I 这类容易看错的字符 |
| 学号原样（不足 8 位补随机） | 表里「学号」那一列 |
| 学号后六位 | 「学号」的后 6 位 |
| 姓名拼音加四位随机 | 例如 `zhangsanK7m2` |
| 自定义规则 | 选中后弹窗里多出一个输入框；它的下面就是「使用说明」链接 |

自定义规则里写 `{{列名}}` 就是取表里那一列的值，`{{学号:6}}` 取那一列的后 6 位。
除了表里的列，还能用四个固定名：登录名、显示名、角色、备注。

规则拼出来的密码不足 8 位会补随机字符——平台的最小密码长度是 8 位。

**自动填充只作用于那一次点击**：补完之后再改任何一个格子都不会被重新补上；
把某一格删空，它就留空，直到再点一次 [自动填充]。

## 预览就是编辑页

读进来之后每一行都能改：登录名、显示名、角色、初始密码、备注。改完会自动重算。

有人出问题时，表格最右边会多出一条窄列，那一行同时标红，格里一颗圆圈感叹号：
鼠标悬停显示原因（登录名被占用、与别的行重复、超出账号上限……），触屏设备无法悬停，
所以这一列只用来在电脑上看原因。

[导入] 亮起来要同时满足三条：

1. 没有登录名冲突
2. 人数没超过账号上限
3. 每一行都有登录名与初始密码

## 账号表要下载

[下载账号表] 导出一份 CSV，内容是当前预览的全部行，含初始密码。

- 浏览器支持「另存为」对话框时由人来选保存位置，文件名只是默认建议
- 这份文件在浏览器里生成，**不存服务器**：关掉这一页就再也拿不到那批初始密码了
- 导入之前会提醒先下载；下载过之后又改了内容、或者在选择保存位置时取消了，
  再点 [导入] 都会先问一句
- 下载这个动作本身记在审计日志里（`account_import_export`，带行数）

## 离开这一页

这一批还没有导入时，从这一页跳走会先问一句「离开导入账号？」：继续编辑，或者离开。
离开之后这一页的内容（含初始密码）就没有了。

## 导入之后

- 每个账号一条审计 `account_create`，另有一条汇总 `account_import`
- **导入的账号一律是「临时密码」**：表里带的密码只是发出去的那一串，本人第一次登录必须先设
  自己的新密码，之后才能用别的功能
- 「角色」选了超级管理员的，建出来就是超级管理员，同样要先改密码
