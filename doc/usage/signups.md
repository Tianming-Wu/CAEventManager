# 报名 - 链接、限制、字段与二维码

报名是一条公开链接：报名成功的人直接写入绑定的名单。

入口是「名单与报名 › 我的报名」。一份报名 = 一条链接 + 一份收获的名单。

## 页面结构

- **我的报名**：页面右上角 [创建报名]；列表底部 [加载更多]
- **报名详情**：页面标题是面包屑，左边一个 [返回（左箭头图标）]；页面右上角依次 [保存设置]
  [下载二维码] [导出报名表] [导出 Excel] [打印报名表] [归档报名]，[下载二维码] 右边是
  [更多格式（三个点图标）]；内容区卡片为 公开链接、基本信息、时间、名额、收集字段、视觉效果、
  报名、提交记录
- **公开页**（`/join/<报名 token>`）：报名人看到的那一页，只有说明、字段与提交按钮，不需要登录

## 归档

报名办完不想再挂在列表里，就点 [归档报名]——**在拥有者眼里它就等于删除**：

- 归档之后这份报名从「我的报名」里消失，自己再也看不到它；公开链接当场失效
  （打开的人看到「这个报名已经结束」），**已经收到的提交记录一条不删**
- 归档**只要一句确认，不用输密码**（超管替别人归档要进 sudo）。归档的报名只有超级管理员
  能在「名单管理 › 已归档」里看到，也只有他能取消归档或彻底删除（这两个要进 sudo）；
  想找回来只能请他代劳
- 名单还在挂着报名时，归档名单会顺带问一句「一并归档？」——在这里归档、或者在那里一并归档，
  都是同一个结果

平台不给普通账号真正的删除：名单与报名都是「归档 → 由超级管理员彻底删除」，活动也一样
（见 [活动](events.md)）。

## 创建

填名称、说明，选**写入哪份名单**，再决定其它几项。确认创建以后自动进入报名详情页。

在报名详情页可以获取报名的链接和二维码。

公开页地址形如 `/join/<报名 token>`，报名不需要登录。提交记录在报名详情的「报名」里查。

## 限制范围

默认关闭：拿到链接就能报名。

开启后只有所选名单内成员可以报名，学号与姓名需要同时匹配。

## 时间与名额

各有一个开关：

- **时间**：开始与结束都能留空，留空表示那一端没有边界
- **名额**：填上限，满了自动停收

## 重复提交

按学号判断。信息与上次完全一致就提示「您已经报过名」；不一致时看「报名后修改」这一项：

- 不允许：提示联系负责人
- 允许：问「您希望更新信息吗」

## 收集字段

学号与姓名固定必填。院系与班级各由一个复选框启用。

其余字段可以自己设置：单行文本、多行文本、数字、单选、日期，分别可标必填。每个字段选一个去向：

- 只留在本次报名
- 写入院系
- 写入班级
- 写成名单里的分组
- 写成名单里的备注

## 视觉效果

四档主题（素色 / 暖色 / 冷色 / 暗色）配一个主色，右侧即时预览。

## 二维码

二维码提供多种下载格式，包括 png, png (1px), svg。扫码可以直接打开报名页。

| 格式 | 用途 |
| --- | --- |
| `PNG · 1 格 1 像素，无留白` | 一个模块一个像素、没有静区、只有黑白两色，文件极小，适合再排版、刻印、贴进文档 |
| `PNG · 1024，带留白` | 打印与张贴，四周留四个模块的白边，扫码更稳 |
| `SVG · 矢量` | 放大到任何尺寸都清楚，白底交给用它的人 |

## 关于短链

短链只作临时用途（见 [shortlinks.md](shortlinks.md)）。不建议长期使用短链作为报名入口，因为平台不对短链有效性做
任何保证。
