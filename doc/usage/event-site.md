# 活动页面与现场 - 活动地址、设置与日志

通过「我的活动」中的 [管理面板] 打开活动后台。已登录面板且拥有活动访问权限的账号可直接进入。

## 活动后台

顶栏显示活动名称及当前账号。页签包括「活动设置」「日志」及模块提供的页面。窄布局下可横向滚动页签。

## 活动设置

- **成员**可用来邀请或管理活动成员。参见[邀请成员](events.md#邀请成员)。
- **活动信息**显示名称和访问地址。重新生成访问地址须确认密码，原地址随即失效。
- **短链**用于创建指向活动页面的临时地址。可用性取决于活动所用模块。参见[短链](shortlinks.md)。

## 日志

「日志」记录当前活动的操作时间、操作人和内容。服务异常时，活动后台右上角会显示提示。参见[通知与服务提示](notices.md)。

## 模块说明

公示页、大屏、签到和其他现场功能取决于活动所用模块。请在「使用文档」目录中打开对应模块的说明。
