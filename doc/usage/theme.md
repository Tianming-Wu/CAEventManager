# 主题 - 切换面板的深浅色

两处入口：

- 顶栏右侧的 [主题（日月图标）]：每点一次换一档，顺序为 [跟随系统] → 与系统相反的外观 → 系统的外观 → [跟随系统]，按住 Shift 点击时反向。图标就是当前取到的外观，跟随系统时显示显示器加日月，其中日月表示系统当前是哪一边。
- 侧栏底部「界面设置」的「主题」：直接选 [跟随系统]、[浅色] 或 [深色]。

切换深浅色时整页交叉淡入，分段控件的指示块滑到新的一格。系统设置了减少动效时不做动画。

选择只保存在本机，不随账号同步。
