# 名单 - 创建、导入与共享名单

名单可用于管理社团成员或参赛人员，并可在创建活动或报名时选用。入口为「名单与报名 › 我的名单」。

## 创建与导入

- 点击页面右上角的 [新建名单]，填写名称。进入名单详情后，可在「手动录入」中添加成员。
- 点击 [导入名单] 可从文件创建名单。向已有名单添加成员时，点击名单详情右上角的 [导入成员]。

支持 CSV、TSV 和 Excel（`.xlsx`）。CSV 和 TSV 可使用「学号、姓名、班级、分组、备注」作为表头。省略表头时，前三列依次为学号、姓名和班级。Excel 读取第一个工作表，首行为表头。文件格式参见[表格导入导出接口](../reference/api-tables.md)。

导入按学号新增或更新成员。导入完成后，页面显示新增、已有和无法读取的记录数量。

## 管理成员

在名单详情可按学号、姓名、分组或备注搜索，并按状态筛选。同一人员出现在多份名单中时，姓名修改会在各名单中生效。

- **标为退出**会保留成员资料，状态变为「已退出」，可恢复为「在册」。
- **移出**会从名单中移除该成员及其分组、标签和备注，操作前须确认。

名单详情右上角提供导出和打印功能。参见[导出与打印](output.md)。

## 可见性

在名单详情右上角点击 [设置]，可修改名称、可见性和写入权限授予方式。私有名单仅拥有者可见，公开名单对登录账号可见。目前组织公开与公开的可见范围相同。

## 写入权限

- 公开名单提供「申请写入权限」。是否必须经拥有者确认，由名单设置决定。参见[写入审批](approval.md#写入审批)。
- 私有名单由拥有者通过「授予写入权限」选择账号，点击 [完成] 保存。
- 获得写入权限的账号可编辑成员资料。写入权限管理和名单归档由拥有者执行。

## 归档

在名单详情的 [设置] 中点击 [归档名单] 并确认。仍有报名关联该名单时，可选择 [全部归档] 一并归档。归档名单从「我的名单」移除，原有成员记录保留。

取消归档与彻底删除参见[名单管理](platform-pages.md#名单管理)。
