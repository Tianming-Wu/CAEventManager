# 服务器与审计 - 查看服务状态、备份和操作记录

站长可在侧栏打开「服务器管理」和「审计日志」。

## 服务器管理

页面显示 CPU 占用、内存占用、运行时长、用户数量和版本。点击右上角的 [刷新] 可更新数据。安全模式下，版本旁显示「安全模式」。

### 服务操作

在「操作」中可执行 [重启服务]、[进入安全模式] 或 [退出安全模式]。操作须通过密码确认。切换安全模式会重启服务。安全模式期间访问活动页面会显示维护提示。

自动重启不可用时，页面会显示提示，请联系部署维护人员处理。

### 备份与服务器特性

「备份」卡片显示备份状态及最近 5 份备份。点击 [立即备份] 创建本地备份，或点击 [设置] 调整备份计划。设置、通知和恢复步骤见[备份](../ops/backup.md)。

「服务器特性」卡片显示服务的可选能力及其状态。两张卡片均可通过标题栏的 [查看文档（问号图标）] 打开对应说明。

## 审计日志

列表显示时间、操作人、动作、对象及说明。可搜索全部记录，或使用列表底部的分页按钮查看更早的记录。

审计日志记录修改操作。通过 API 令牌或运维助手执行的修改会标明来源。各活动自身的操作记录位于活动后台的「日志」。参见[活动页面与现场](event-site.md#日志)。
