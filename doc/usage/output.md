# 导出与打印 - 表格与纸张

数据有多种导出形式。可以导出成表格以在 Excel 等应用中使用，或者可以打印成现场使用的纸质文件。

## 导出

| 位置 | 按钮 | 输出 |
| --- | --- | --- |
| 名单详情 | 导出 CSV | 一份 CSV |
| 名单详情 | 导出 Excel | 一份 xlsx |
| 报名详情 | 导出报名表 | 一份 CSV |
| 报名详情 | 导出 Excel | 一份 xlsx |

- **两种都只有表头与数据行**：不含标题、不含说明、不含合计
- CSV 带 BOM。使用 Excel 打开时不会出现乱码，学号不会识别为数字，前导零不会丢失
- xlsx 使用全文本单元格，学号不会变成数字、前导零不会掉
- xlsx 的读写可以识别文本、数字和布尔值，空行会被跳过，合并单元格只取左上角；公式、图表、多个工作表不处理
- 往名单里导入 xlsx 见 [rosters.md](rosters.md)，接口形式见
  [../reference/api-tables.md](../reference/api-tables.md)

## 打印名单

名单详情右上角的「打印名单」，另开一张纸。一张简单的表：序号、学号、姓名、院系、班级；
有人分组就多一列分组，有已退出的人就多一列状态。

- 每页左下角标「第 N / M 页」，换页时表头重复
- 可配置显示标题，默认关闭
- 屏幕上所见即为实际打印效果。（无法百分百保证，请自行确认）

## 打印报名表

报名详情右上角的「打印报名表」。默认为**已报名单**：学号、姓名、院系、班级与自定义字段。

- 每页左下角标「第 N / M 页」
- 可配置显示标题与报名二维码，默认关闭
- 「空白表」作为备选选项
- 纸张颜色不会受深色模式干扰
