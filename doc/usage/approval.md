# 审批 - 注册申请与写入审批

平台上有两种等待批准的事：新账号要不要放进来，以及谁能改这份名单。

## 页面结构

- **写入审批**：页面标题是「待我审批」，内容区两块——待我审批、我发出的申请
- **注册申请**：内容区两块——待审核、最近处理；每条的操作列有 [通过] 与 [拒绝]，拒绝要写理由
- **活动申请**：目前是空页

## 注册申请

「活跃审批 › 注册申请」，超级管理员及以上可见。分待审核与最近处理两块。

- 通过：账号变成正式的管理员，可以进全部普通功能
- 拒绝：写明理由，对方能看到

## 写入审批

「名单与报名 › 写入审批」，标题是「待我审批」。这里集中等着你批的名单写入权限申请。

批不批只对「等拥有者确认」的名单有意义：设成申请即刻生效的名单不会在这里出现。
名单的写权限规则见 [rosters.md](rosters.md)。

## 活动申请

「活跃审批 › 活动申请」现在还没有接入：新活动默认自动通过，这一页暂时是空的。

## 谁批谁

| 事 | 谁 |
| --- | --- |
| 注册申请 | 超级管理员、站长 |
| 名单写入申请 | 那份名单的拥有者或管理者 |
| 改角色、封禁账号 | 超级管理员及以上，要重新输一次密码 |
