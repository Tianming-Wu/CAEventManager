# 运维助手 - 配置模型、查询与执行操作

在侧栏打开「运维助手」，可查询平台数据、咨询平台用法及执行操作。助手沿用当前账号的权限。修改操作须经批准。

## 页面结构

- **副标题**显示当前模型与存档用量。尚未配置模型时，页面提示打开右上角的「模型设置」。
- **页面右上角**：[模型设置（齿轮图标）] [导出这段对话（下载图标）]
  [新建会话（对话气泡加号图标）]。新会话尚无存档时，导出按钮不可用。
- **内容区**：中间是对话，回答上方显示工具标签，底部为输入框与 [发送]。
- 窄模式下，在输入框右上角有 [全屏编辑（四角图标）]

## 模型设置

平台不提供对话模型，使用者需要自行配置。每个账号独立保存模型设置。配置入口在右上角的「模型设置」：

| 项 | 说明 |
| --- | --- |
| 接口地址 | 兼容 OpenAI 的端点，例如 `https://api.deepseek.com`。留空时使用默认接口地址 |
| 模型 | 留空时使用默认模型。点击 [获取模型] 可查看接口地址提供的模型 |
| 密钥 | 填写后可保存新密钥。留空时保留已保存的密钥。点击 [清除密钥] 可移除密钥 |

展开「高级设置」可调整上下文上限。

| 项 | 说明 |
| --- | --- |
| 上下文上限 | 单位为 token。留空时按模型使用预设上限 |

## 提问与查看回答

在输入框描述需要查询的数据或执行的操作，点击 [发送]。可以中断回答并补充说明。回答上方的工具标签可展开查看详情，回答和代码块均可复制。站内文档链接在新标签页打开。

## 查询功能

以下为可用的查询功能。

| 名称（工具） | 作用 | 可用角色 |
| --- | --- | --- |
| 读取活动列表 | 列出当前账号可见的活动及其活动角色 | 所有人 |
| 读取活动数据 | 查看活动公示数据，包括人数、签到、奖票、奖品和最近中奖记录 | 所有人 |
| 读取名单列表 | 列出名单（我参与的 / 我创建的 / 全部） | 所有人 |
| 读取名单成员 | 查看名单成员，可按学号或姓名筛选 | 所有人 |
| 读取报名列表 | 列出报名项：状态、已报人数、名额、关联名单 | 所有人 |
| 读取报名记录 | 查看指定报名的提交记录 | 所有人 |
| 检索人员 | 按学号或姓名检索人员 | 所有人 |
| 读取文档清单 | 列出使用文档、参考和模块说明 | 所有人 |
| 读取文档 | 查看指定文档的正文 | 所有人 |
| 读取审计日志 | 最近的审计日志 | 超级管理员和站长 |
| 读取服务器状态 | 服务器状态与在线人数 | 仅站长 |

## 批准操作

助手可写入或移出名单成员、修改报名设置、修改活动名称和会话标题。需要提权的操作须在相应页面执行。

- 点击 [批准] 执行待确认的操作，执行结果会显示在对话中。
- 点击 [拒绝] 取消待确认的操作。
- 切换会话、刷新页面或超过五分钟后，当前批准请求失效。切换至其他页面时，侧栏「运维助手」会标记待批准的操作。

## 文档查询

助手可查询「使用文档」中的使用说明、参考和模块说明。参见[使用文档](platform-pages.md#使用文档)。

## 对话存档

点击输入框上方的会话标题，打开会话列表，可新建、重命名或删除会话。页面右上角的 [导出这段对话] 可将已有对话保存为 Markdown。

存档达到配额后，页面会提示清理会话。站长可在「用户管理」中调整账号的存档配额。

上下文用量指示器位于会话标题栏右侧。悬停或点击可查看估算用量及上限。可在「模型设置 › 高级设置」中设置「上下文上限」。
