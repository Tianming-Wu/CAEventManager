# 审批 - 注册申请与写入审批

平台审批分为两类：

- 账号注册申请
- 名单写入权限申请

## 页面结构

- **写入审批**：页面标题是「待我审批」，内容区两块——待我审批、我发出的申请
- **注册申请**：内容区两块——待审核、最近处理；每条的操作列有 [通过] 与 [拒绝]，拒绝要写理由
- **活动申请**：目前是空页

## 注册申请

「活跃审批 › 注册申请」，超级管理员及以上可见。分待审核与最近处理两块。

- 通过：账号注册成功，默认为管理员，可以登录
- 拒绝：拒绝账号注册。理由会发送给申请人

## 写入审批

「名单与报名 › 写入审批」，标题为「待我审批」。这里集中待审批的名单写入权限申请。

审批动作只对于设置为「等拥有者确认」的名单有意义：设置为申请即刻生效的名单不会在这里出现。
名单的写权限规则见 [rosters.md](rosters.md)。

## 活动申请

「活跃审批 › 活动申请」未实现：新活动申请默认自动通过。

## 角色

| 事项 | 角色 |
| --- | --- |
| 注册申请 | 超级管理员、站长 |
| 名单写入申请 | 名单的拥有者或管理者 |
| 改角色、封禁账号 | 超级管理员及以上 (sudo) |
