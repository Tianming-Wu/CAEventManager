# 服务器与审计

这两页只有站长能看到。

## 服务器管理

机器占用、运行时长、用户（在线 / 注册）与版本号都在这一页。顶栏左侧的 CPU 与 MEM 也是它的缩写版。

「运维操作」里的下载数据备份、重启服务、查看日志**还没有接入**，现在这几个动作只能在服务器上
跑脚本做，见 [`../ops/deploy.md`](../ops/deploy.md)。

## 审计日志

记每一次写入：谁、什么时候、对哪个对象、改了什么。表中一列一件事，翻到底点「加载更多」。
搜索在服务端完成，所以搜的是全部记录，不只是已经翻出来的这些。

审计日志只记改动，不记查看。同一个人带着 API 令牌操作时，操作人仍记本人，
说明后面标着用的是什么令牌。

## 活动自己的日志

每个活动后台还有一份自己的操作日志，只记这场活动里的事，给现场复盘用。两者分开：
面板的审计日志是整台机器的账。
