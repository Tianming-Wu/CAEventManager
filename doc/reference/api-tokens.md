# API 令牌 - 生成、范围与审计

给平台之外的程序用：脚本、群机器人、别的 Agent。入口在「账户信息 › API 令牌」，一人一张或多张。

## 建一张

- 形如 `cae-` + 43 位随机字符。**在浏览器里生成**：只有 sha256 与前四位、后五位发到服务端，
  明文既没经过网络也没进过服务端内存
- 之后任何地方只显示 `cae-abcd•••••wxyz9`，明文只在生成的那一刻出现一次
- 有效期可选「永不过期 / 30 天 / 90 天 / 一年」，随时可吊销，吊销即刻失效
- 浏览器拿不到 WebCrypto 时（例如从局域网用 http 打开）退回服务端生成，界面会说明这一次是
  服务端生成的

## 用

```
Authorization: Bearer cae-…
```

带令牌的请求不必带 `X-Requested-With`——那是为"浏览器会自动携带 cookie"设的防线，令牌没有
这个问题。

## 三档范围

| 范围 | 能做什么 |
| --- | --- |
| 读取 | 列表、详情、导出 |
| 写入 | 名单、报名、活动设置的日常改动 |
| 平台管理 | 账号、活动生命周期、外部资源 |

账号本身的权限仍然生效，令牌只能在其下再收窄。

## 它做不到

- 发新令牌、吊销令牌
- 改账号自己的信息（称呼、登录名、头像、密码）
- 需要重新输密码的动作
- 超出自己范围的操作

## 审计

审计里操作人仍记本人，说明后面带一句 `令牌「群机器人」`——事后分得清是人点的还是程序调的。
