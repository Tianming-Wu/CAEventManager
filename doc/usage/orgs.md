# 组织 - 归属关系与组织内身份

组织记录的是一份归属：谁属于哪个组织，在其中是什么身份。组织内的身份不带来平台权限，不能修改账号角色、重置密码或删除账号。活动暂不挂在组织上。

两处入口，看的人不一样：

| 页面 | 侧栏 | 可见范围 | 用途 |
| --- | --- | --- | --- |
| 组织管理 | 组织管理 | 超级管理员及以上 | 平台侧查看与维护全体组织，改动须 sudo |
| 我的组织 | 我的组织 | 管理员及以上 | 成员看自己参加的组织 |

## 我的组织

侧栏「我的组织」。内容区一张卡片一格，列出自己参加的组织：名称、简介、我的身份与成员人数。卡片上方留着背景图的位置，用于摆放该组织的外观图。

右上角 [加入组织] 暂时不可用，邀请码机制尚未确定。

## 组织管理

侧栏「组织管理」。

内容区一张组织表：列为 名称 / 标识 / 成员 / 状态 / 操作。成员列写出人数与负责人人数，例如「2（负责人 1）」；各人的身份在详情页里看。表头右侧是搜索框，可按组织名称或标识搜索。

点击组织名称或操作列的 [管理]，进入「组织管理 › 组织」。点击页面右上角的 [创建组织]，进入「组织管理 › 创建组织」页面。

这一页与组织详情页都面向平台侧，**每一处改动都需要 [sudo 模式](sudo.md)**，包括移出成员与调整身份。

### 组织详情

| 区块 | 内容 |
| --- | --- |
| 基本信息 | 名称与简介可改，点击 [保存] 生效；组织标识只读 |
| 成员 | 表列为 成员 / 身份 / 加入时间 / 操作，人数写在标题右侧 |
| 状态 | [归档]；已归档时是 [恢复] 与 [彻底删除] |

成员的身份在表格里直接选：负责人、管理、成员。点击 [添加成员] 进入选人弹窗，已经在组织里的人不再出现在名单里。

点成员行末的 [移出] 会先确认一次，确认后把该账号移出组织；之后可以再加回来。每个组织至少要保留一位负责人，最后一位负责人不能被移出，也不能改成别的身份。

## 创建组织

「创建组织」页面左侧是基本信息，右侧是外观。

| 字段 | 说明 |
| --- | --- |
| 名称 | 必填，最长 40 个字 |
| 组织标识 | 必填，3 到 24 位小写字母、数字、连字符与下划线，例如 `cs-club`。建好后不可更改 |
| 简介 | 选填，最长 200 个字 |
| 负责人 | 必填，至少一位，可以有多位 |
| 管理 / 成员 | 选填，可以之后再添加 |

组织标识只接受小写字母、数字、连字符与下划线，其他字符输入时不进入输入框。输入框失去焦点时，不足 3 位的内容给出提示，输入框同时标红。

点击 [负责人]、[管理] 或 [成员] 左侧的加号进入选人弹窗，勾选后按 [完成]。已在其中一个框中选定的人，在另外两个框中灰显，不能再选。要移到另一个身份，先在这个框里点击头像右侧的 ×，再到另一个框里重新选。

「外观」一栏预留了背景图的位置，用作「我的组织」卡片的背景。上传入口尚未开放。

填写完成后点击页面右上角的 [创建组织]。组织创建后回到「组织管理」，新组织出现在列表里。填了一半离开这一页时，先提示内容不会保留。

## 组织内身份

三种身份：负责人、管理、成员。「我的身份」在「我的组织」的卡片上写着。

每个组织至少要保留一位负责人。

## 归档与彻底删除

组织不再使用时在详情页点击 [归档]，确认后归档。归档把成员关系折进组织那一行存放，明细行随之删除；组织仍留在列表里，状态标为「已归档」，成员数与负责人人数照旧显示。归档的组织在详情页只能看，不能改名称或成员，[归档] 换成 [恢复]。

点击 [恢复] 展开成员关系，组织回到正常状态。

[彻底删除] 只对已归档的组织出现，只对站长可见，并且须进入 sudo 模式。删除后不能恢复，成员的归属记录一并消失。

## 导入账号中的组织

批量导入账号的「组织」列目前是预留字段，导入时不会写入组织归属。参见[导入账号](account-import.md)。
