# 导出与打印 - 下载和打印名单与报名表

数据有多种导出形式。可以导出成表格以在 Excel 等应用中使用，或者可以打印成现场使用的纸质文件。

## 导出

| 位置 | 按钮 | 输出 |
| --- | --- | --- |
| 名单详情 | 导出 CSV | 一份 CSV |
| 名单详情 | 导出 Excel | 一份 xlsx |
| 报名详情 | 导出报名表 | 一份 CSV |
| 报名详情 | 导出 Excel | 一份 xlsx |

- **两种都只有表头与数据行**：不含标题、不含说明、不含合计
- Excel 导出保留学号的前导零。
- 导入操作参见[名单](rosters.md)。接口及格式约定参见[表格导入导出接口](../reference/api-tables.md)。

## 打印名单

点击名单详情右上角的 [打印名单]。打印表包含序号、学号、姓名、院系和班级。名单含分组或已退出的成员时，分别增列分组或状态。

- 每页左下角标「第 N / M 页」，换页时表头重复
- 可配置显示标题，默认关闭
- 打印前可在浏览器的打印预览中核对版面

## 打印报名表

报名详情右上角的「打印报名表」。默认为**已报名单**：学号、姓名、院系、班级与自定义字段。

- 每页左下角标「第 N / M 页」
- 可配置显示标题与报名二维码，默认关闭
- 「空白表」作为备选选项
- 打印使用浅色背景
