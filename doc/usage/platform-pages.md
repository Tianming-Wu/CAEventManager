# 平台管理页 - 用户管理、模块管理与展示屏幕

「用户管理」、「活动管理」和「名单管理」功能只对超级管理员及以上开放。

站长另有审计日志与服务器管理，见 [server.md](server.md)，**模块管理页面只对站长可见**。

## 用户管理

侧栏「用户管理」。

内容区一张账号表：列是 用户名 / 显示名 / 角色 / 状态 / 最近登录 / 操作；
表头右侧是搜索框，列表底部 [加载更多]。列表上方写着「共 N 个账号」；这个实例设了账号总数上限时
后面跟着「上限 M」，到顶了还会标「已满」——那时注册口不再接受新申请。

每行的操作列可以改角色、封禁或停用、重置密码、[调整存档配额]（助手对话的存档上限）。
账号注册审核在「活跃审批 › 注册申请」。

### 彻底删除账号

它**只对已停用的账号出现**，而且需要满足特定条件可用：

| 账号状态 | 弹窗 |
| --- | --- |
| 正常 / 待审核 / 已封禁 | 「彻底删除」不可见 |
| 已停用，但停用没满 `delete_account_after_days` 天 | 有，灰显并无法点击；鼠标悬停显示剩余时间 |
| 已停用且停满，但名下还有在用的活动或名单、报名 | 有，灰显并无法点击；鼠标悬停提示原因 |
| 已停用、停满、名下没有在用的东西 | 可点，超管及以上 (sudo) |

随账号删除的数据：会话、API 令牌、助手存档、头像、活动席位、站内通知、草稿、预设收藏。
**审计日志不会被删除**。

已归档的活动不会影响账号删除。名单与报名可以使用「名单管理」功能转移所有权，或者删除。

## 活动管理

侧栏「活动管理」。

内容区两张表：**当前活动**与**归档的活动**，两张表列一致：活动 / 活动号 / 负责人 /
时间（当前活动是创建时间，归档则是归档时间）/ token / 操作。活动名旁边如果挂着红色的
「不可用」胶囊，说明它的依赖链不完整（悬停或点击可以查看原因）。
**首列的活动名可以点击**，和「详情」按钮一致。详情内会显示活动的高权限操作：

| 动作 | 当前活动 | 已归档 |
| --- | --- | --- |
| 打开活动设置 ↗ | ✓ | — |
| 下载数据 / 下载完整数据 | ✓ | ✓（含归档包） |
| 转移负责人 | ✓ | — |
| 回收站内资源 | ✓ | — |
| 强制归档 | ✓ | — |
| 取消归档 | — | ✓ |
| 彻底删除 | — | ✓ |

除了「打开活动设置 ↗」「转移负责人」（负责人自己做时不需要提权），其余需要 sudo。
见 [sudo.md](sudo.md) 了解 sudo 模式。

**取消归档时，负责人账号可以不存在**：
出现这种情况时，活动负责人会显示为「账号已删除」。如果此时需要 [取消归档] ，会需要先选择新的负责人，
确认之后转移与恢复一起完成。

## 名单管理

侧栏「名单管理」。

内容与活动管理类似：
内容区两张表，**名单**与**报名**，点名称打开详情，高权限动作都在详情弹窗里。

第一张卡片顶上有一对切换 [当前] [已归档]：**当前**是还在用的名单与报名（默认），
**已归档**是拥有者收起来的那批，这一栏的最后时间列变成归档时间。
**归档等于拥有者那边的删除**——他自己再也看不到，所以这一页是唯一能翻出归档名单与报名的地方
（活动那边同理：「活动管理 › 归档的活动」）。

| 表 | 列 |
| --- | --- |
| 名单 | 名单 / 拥有者 / 可见性 / 人数 / 更新时间 / 操作 |
| 报名 | 报名 / 拥有者 / 状态 / 已报名 / 更新时间 / 操作 |

详情弹窗内动作按对象类型决定：

| 类型 | 动作 |
| --- | --- |
| 当前 | 打开 ↗ / 转移拥有者 / 归档 |
| 已归档 | 取消归档 / 彻底删除 |

- **归档**：把这份名单或报名从拥有者的列表里收起来（拥有者自己也能做，见
  [名单](rosters.md) 与 [报名](signups.md)）。
- **取消归档**：放回普通列表，拥有者又能打开它
- **彻底删除**：只对归档过的对象开放，不可逆——这一步是平台唯一的真正删除
- **转移拥有者**：从选人弹窗里挑一个人，交给他；**原来的拥有者会保留一份写入权限**，
  免得自己建出来的东西被收走之后想改又没门路

上述动作都需要 sudo 模式。

## 模块管理

侧栏「模块管理」，**只有站长能看到**：装与停都是整台机器的事。内容区一张表：模块 / 版本 /
作者 / 引用计数 / 操作，右上角 [导入模块]，最右一列是 [卸载]（自己装的才有）与 [停用] / [启用]。
「引用计数」是还在用这个模块的活动数。

### 导入

[导入模块] 打开文件选择窗口。支持 zip 格式。
压缩包内需要包含模块目录（`module.json` 在最外层，或者整个目录一起打包）。

- 解析完会列出模块清单：模块名、标识、版本、作者、体积，以及它申请的能力。
  如果模块申请了高危能力，会突出显示「模块申请以下高危权限」。
- 平台自带的模块不可卸载，也不能用同名的模块覆盖。
- 部署实例上可手动操作：把目录放进 `modules/`，重启后同样生效。注意这样做会绕过高危权限确认，请谨慎操作
- 暂时不支持模块更新。可以先卸载旧模块再导入新模块，但请确认数据格式兼容。这是模块实现细节，平台无法保证。

### 停用与启用

停用与启用需要站长进入 sudo 模式操作。

- 停用之后，使用这个模块的活动立刻不可用：正在运行的活动会被停用。
  说明页写着「此活动不可用 / 此活动必需的资源已被管理员停用」；活动接口返回 503。
  「我的活动」的卡片在标题右边多一枚红色「不可用」胶囊，悬停或点击显示原因
- 活动数据会被冻结。停用的模块也不再出现在创建活动的列表里，它的预设一并不可用
- 启用之后活动立刻恢复，刷新页面即可。

### 高危权限

有的模块会申请平台保留的高危能力（`super.` 前缀，例如不受限制的短链跳转）。这类模块在
名称右侧显示红色「高危」胶囊，悬停或点击可以看到申请的高危权限列表。

高危权限**申请即生效**，平台没有二次授权机制。如果模块来源不可信，请谨慎使用。

高危权限调用会在审计日志留下记录。

## 展示屏幕

侧栏「外部资源 › 展示屏幕」。页面右上角 [导入]；内容区三块：可用的屏幕、导入说明、引用方式。

- 「可用的屏幕」列出内置与导入的展示屏幕，各自有标识与体积
- 「导入说明」写着导入要求：包内要有 `screen.html`，只收样式表、脚本与图片，压缩包 2 MB 以内、
  解压大小 8 MB 以内
- 活动用哪一份屏幕，在活动后台的「活动设置」里选

## 使用文档

侧栏第一节、「外部资源」下面那一项**使用文档**：它不会在面板里换页，而是在**新标签页**打开
（右边有一枚"开新窗口"的小标记）。那一页是独立的一套骨架：

- 左边是按目录分组的树：使用说明、参考、各模块的现场说明；组可以点标题收起/展开
- 右边是正文，可以滚；顶栏写着当前这一篇的位置（例如「使用说明 › 名单 - 建、导入、导出」）
- 顶栏右边两颗按钮：[↩] 回控制台，[太阳/月亮] 切换深浅色。深浅色**保存在浏览器中**，
  第一次打开时沿用面板状态。
- 地址包含文档路径（`docs#/usage/rosters.md`）；后面接 `~某一节`
  就是直接落到那一节（`docs#/usage/assistant.md~它会查文档`），这两种链接都可以直接发给别人打开
- 正文上方是大标题，下面一行显示上次更新日期
- 默认只展开当前这文档所在的分组；手动操作展开或收起的分组在切换文档时会保持原样
- 正文里的链接就是普通 Markdown，路径相对当前这一篇：`[审批](approval.md)`、
  `[词表](../reference/glossary.md)`。指向站内文档时渲染成带文件图标的蓝色链接；
  指向不存在文档的写成红色「审批（链接已断）」、禁止点击；站外 `http(s)` 链接前面带一枚
  开新窗口的小箭头，点了在新标签页打开；其它一律只显示文字
- 可以跳到某一篇里的某一节：`[登录名](account.md#登录名)`，本文内写 `[登录名](#登录名)`。
  锚点取标题正文，转小写、空格换连字符、去掉标点
- 图片写 `![说明](shot.png)`（相对当前这一篇）：只认 `doc/` 与模块目录下的
  png / jpg / webp / gif / svg，单张 2 MB 以内；站外图片暂不支持
- 运维助手回答里的站内文档链接是同一套：路径与文档清单里的写法一致、去掉 `doc/` 前缀
  （`[名单](usage/rosters.md)`），后面接 `#标题` 也能落在那一节，点开在新标签页打开那一篇
- 手机上左边那列收进抽屉，顶栏左边有 [目录]
- 只包含操作指南、参考、模块说明。开发与运维文档不包含在内。
