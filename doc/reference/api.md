# 接口与 API 令牌

面板自己的前端就用这套接口，所以它们不是"内部接口"再包一层——同一个进程、同一套权限、同一份审计。

## 路由家族

```
/                  主面板登录页（/login 是同一页）
/register          主面板注册
/panel             主面板控制台
/print             打印页：名单 / 报名单（?kind=roster|signup&id=，可选 mode=blank）
/panel_static/*    面板静态资源
/api/panel/*       面板接口

/<token>/          活动公示页（只读，无鉴权）
/<token>/screen    大屏
/<token>/checkin   自助签到（须带 ?t= 时效 token）
/<token>/admin     活动后台（用面板账号登录）
/<token>/login     跳面板登录，登录后回到该活动后台
/<token>/api/*     活动接口
/s/<code>          限时短码跳转
```

路径里出现已知活动 token 时按活动处理，否则把剩余路径按面板路由匹配——所以本机直连、
反向代理前缀、将来的子域名都不用改代码。`config.json` 里的 `public_base_prefix` 只用于生成
绝对链接（二维码、分享链接、Cookie 路径），不参与路由判定。

## 浏览器侧的鉴权

- 登录后拿到会话 cookie（`HttpOnly`，路径限定在挂载前缀下）
- 所有写请求要带 `X-Requested-With: CAEventManager`——跨站表单设不了自定义头，这是 CSRF 防线
- 敏感操作返回 `403` + `sudoRequired`，界面拦一次密码后再重发同一个请求
- 每个回答都带 `version`（服务版本）与 `revs`（各对象的版本号），页面据此判断要不要刷新、
  以及写入有没有冲突

## API 令牌

给平台之外的程序用：脚本、群机器人、别的 Agent。入口在「账户信息 › API 令牌」，一人一张或多张。

- 形如 `cae-` + 43 位随机字符。**在浏览器里生成**：只有 sha256 与前四位、后五位发到服务端，
  明文既没经过网络也没进过服务端内存；之后任何地方只显示 `cae-abcd•••••wxyz9`
- 用法：`Authorization: Bearer cae-…`。带令牌的请求不必带 `X-Requested-With`
  （那是为"浏览器会自动携带 cookie"设的防线，令牌没有这个问题）
- **三档范围**：读取（列表、详情、导出）／写入（名单、报名、活动设置的日常改动）／
  平台管理（账号、活动生命周期、外部资源）。账号本身的权限仍然生效，令牌只能在其下再收窄
- 令牌**做不到**：发新令牌 / 吊销令牌、改账号自己的信息（称呼、登录名、头像、密码）、
  需要重新输密码的动作、超出自己范围的操作
- 有效期可选「永不过期 / 30 天 / 90 天 / 一年」，随时可吊销，吊销即刻失效
- 审计里操作人仍记本人，detail 后面带一句 `令牌「群机器人」`——事后分得清是人点的还是程序调的
- 浏览器拿不到 WebCrypto 时（例如从局域网用 http 打开）退回服务端生成，界面会说明这一次是
  服务端生成的

## 名单与报名的表格导出

```
GET  /api/panel/roster/export.csv?id=<名单>        GET  /api/panel/roster/export.xlsx?id=<名单>
GET  /api/panel/signup/export.csv?id=<报名>        GET  /api/panel/signup/export.xlsx?id=<报名>
POST /api/panel/roster/import.xlsx?id=<名单>        （body 是 xlsx 的原始字节）
POST /api/panel/roster/import.xlsx?name=<新名单>    （没有 id 就用这份表格开一份新名单）
```

- **导出的表只有表头 + 数据行**：不加标题、不加说明、不加合计。第一行就是列名
- CSV 带 BOM，Excel 双击直接打开；xlsx 是文本单元格，学号不会变成数字、前导零不会掉
- xlsx 的读写是 `xlsx.py` 里最小的一份实现：一个工作表、文本单元格。读的时候认得
  inlineStr / 共享字符串 / 数字 / 布尔，空行跳过，合并单元格只取左上角；
  公式、图表、多个工作表不处理（也不假装能处理）
- 导入上限 4 MB；不是 xlsx 的文件会被拒并说明原因

## 事件流

- 面板：`GET /api/panel/stream`（需要登录）
- 活动：`GET /<token>/api/stream`（不需要登录，只收本活动的变化）

服务端在每次成功写入之后把相关对象的版本号加一，通过事件流推送。客户端收到后重新读当前页面；
连不上时退回轮询（大屏 1.5 秒、公示页 5 秒），连上之后轮询降为半分钟一次的对账读取。
公示页的读取带 `ETag`，没有变化时回 304。

## 错误约定

| 状态 | 含义 | 界面处理 |
| --- | --- | --- |
| 401 | 未登录或会话过期 | 回登录页，登录后回到原页面 |
| 403 | 没有这个权限（或需要重新输密码） | 说明原因；`sudo` 时拦一次密码 |
| 409 | 同一对象被别人先改过 | 提示「另一个会话刚刚改过这一项」，以服务端状态为准 |
| 413 | 请求体过大（例如存档配额满了） | 说明并提示清理 |
| 502 | 外部端点失败（模型接口） | 说明是调用模型失败 |

错误体统一是 `{ok: false, error: "给用户看的一句话"}`。
