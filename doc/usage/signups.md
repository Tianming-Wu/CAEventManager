# 报名

报名是一条公开链接：报名成功的人直接写进某份名单。

入口是「名单与报名 › 我的报名」。一份报名 = 一条链接 + 一份收获的名单。

## 创建

填名称、说明，选**写入哪份名单**，再决定其它几项。填完在详情页拿到链接与二维码。

公开页地址是 `/join/<报名 token>`，不需要登录。提交记录在报名详情的「报名」里查。

## 限制范围

默认关闭：拿到链接就能报名。

开启后只有所选名单内的成员能报，学号与姓名都要对上。

## 时间与名额

各有一个开关：

- **时间**：开始与结束都能留空，留空表示那一端没有边界
- **名额**：填上限，满了自动停收

## 重复提交

按学号判断。信息与上次完全一致就提示「您已经报过名」；不一致时看「报名后修改」这一项：

- 不允许：提示联系负责人
- 允许：问「您希望更新信息吗」

## 收集字段

学号与姓名固定必填。院系与班级各由一个复选框决定收不收。

其余字段自己加：单行文本、多行文本、数字、单选、日期，可标必填。每个字段选一个去向：

- 只留在本次报名
- 写入院系
- 写入班级
- 写成名单里的分组
- 写成名单里的备注

## 视觉效果

四档主题（素色 / 暖色 / 冷色 / 暗色）配一个主色，右侧即时预览。这是给报名人看的页面，
与自己的界面设置无关。

## 二维码

报名详情右上角的「下载二维码」给一张 720 见方、带白边的 PNG；右边的 ⋮ 是更多格式：

| 格式 | 用途 |
| --- | --- |
| `PNG · 1 格 1 像素，无留白` | 一个模块一个像素、没有静区、只有黑白两色，文件极小，适合再排版、刻印、贴进文档 |
| `PNG · 1024，带留白` | 打印与张贴，四周留四个模块的白边，扫码更稳 |
| `SVG · 矢量` | 放大到任何尺寸都清楚，白底交给用它的人 |
