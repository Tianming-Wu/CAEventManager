# API 令牌 - 生成、范围与审计

API 令牌供脚本、群机器人等外部程序访问平台接口。在「账户信息 › API 令牌」可管理一个或多个令牌。

## 创建与吊销

点击 [新建令牌]，设置有效期并至少选择一项权限。有效期可选「永不过期」「30 天」「90 天」或「一年」。完整令牌仅在创建时显示，请在关闭弹窗前复制。吊销后立即失效。

## 接口认证

```
Authorization: Bearer cae-…
```

使用 API 令牌认证时可省略 `X-Requested-With` 请求头。

## 权限范围

| 范围 | 能做什么 |
| --- | --- |
| 读取 | 列表、详情、导出 |
| 写入 | 名单、报名、活动设置的日常改动 |
| 平台管理 | 账号、活动生命周期、外部资源 |

令牌的有效权限为所选范围与账号权限的交集。

## 操作限制

- 创建或吊销令牌
- 修改账号资料（显示名、登录名、头像、密码）
- 执行须确认密码的操作
- 超出自己范围的操作

## 审计

审计日志使用令牌所属账号作为操作人，并在说明中标明令牌来源。
