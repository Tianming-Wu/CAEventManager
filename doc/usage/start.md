# 开始用 - 注册、审核与界面骨架

打开服务地址即登录页，注册入口是 `/register`。

## 总览页

进面板先看到「总览」：上面四张计数牌（我的活动 / 我的名单 / 我的报名 / 待处理邀请），
下面是「最近操作」列表，右下角有进「审计日志」的入口（能看审计的人才出现）。

能评审、能看账号清单的人，这里还多两块：待审核申请、账号总数。

## 注册与审核

自己填登录名、称呼、密码提交，账号状态是「管理员 · 待审核」：这时已经能登录，但看不到用户管理与
活动管理。超级管理员或站长在「活跃审批 › 注册申请」里通过之后，才进入全部功能。

忘记密码找站长重置。

## 侧栏

从上到下：

| 分组 | 页 |
| --- | --- |
| — | 总览、运维助手、我的活动、预设管理 |
| 名单与报名 | 我的名单、我的报名、写入审批 |
| 外部资源 | 展示屏幕 |
| — | 用户管理、活动管理（超级管理员及以上） |
| 活跃审批 | 注册申请、活动申请（超级管理员及以上） |
| — | 服务器管理、模块管理、审计日志（仅站长） |

最下面是「界面设置」与自己的账号卡片，点卡片进「账户信息」。

## 顶栏

左边是产品名与版本号，站长这里还多一条机器占用；右边是通知。

新的通知进来时铃铛上出现圆点。点开是通知中心，别人发的通知与服务降级提示都在里面，
见 [notices.md](notices.md)。

## 宽屏与窄屏

布局跟着窗口宽度走，与设备类型无关：

- **大于 1100px**：侧栏带文字，一直在左边
- **761～1100px**：侧栏只留图标；分组里的子项收进抽屉，点图标展开
- **760px 及以下**：侧栏整个收起，顶栏左侧出现 [打开导航（三条横线图标）]，
  点它侧栏从左边滑出；内容区变成单列

窄屏下表格横向滚动（第一列与操作列贴边，滑动时不动），日期与时刻改用系统选择器。
