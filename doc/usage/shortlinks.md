# 短链 - 生成活动的临时访问地址

短链形如 `/s/AB3D7KM`，可跳转至指定的活动页面。长期使用的公告或二维码应引用活动原地址。

## 创建短链

在活动后台的「活动设置」中找到「短链」。是否提供该功能取决于所用模块。

| 设置 | 说明 |
| --- | --- |
| 指向 | 选择或填写活动内的相对路径，例如 `screen`。留空时指向公示页 |
| 有效期 | 以分钟计，最长 30 天。留空时不设有效期 |
| 最多访问次数 | 留空时不限次数 |

短链编号不区分大小写。页面底部列出当前短链、指向、剩余有效期及访问次数。

## 管理短链

每个活动可同时持有多条短链。达到平台上限时，须先删除已有短链或等待其失效。

点击列表右侧的 [删除] 可使短链立即失效。短链达到有效期或访问次数上限时也会失效。活动归档后，其短链全部失效。

超级管理员和站长可在「活动管理」中回收活动的站内资源。参见[平台管理页](platform-pages.md#活动管理)。
