# 关于 - 版本、作者与反馈

CAEventManager 是面向学生社团的活动管理平台。面板提供活动、名单和报名管理。各活动的页面与现场操作由所用模块决定。

## 版本

当前版本显示于面板侧栏底部、使用文档标题旁及 404 页面底部。
