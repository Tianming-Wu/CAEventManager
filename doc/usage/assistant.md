# 运维助手 - 配模型、提问与对话存档

侧栏第二项「运维助手」，提供基于 LLM 的平台服务，包括信息查询和操作。

助手权限和当前登录账号一致。助手可见的内容和可操作的内容和登录用户没有区别。

助手不知道无法访问的内容。助手的任何实际修改操作都需要用户手动审批才会执行。如果选择“拒绝”，
则任何内容都不会被修改。

## 页面结构

- **页面标题与副标题**：标题是「运维助手」；副标题写当前模型与存档用量，还没配密钥时提示设置密钥。
- **页面右上角**：[模型设置（齿轮图标）] [导出这段对话（下载图标）]
  [新建会话（对话气泡加号图标）]。新会话没有存档，因此导出键会在新会话页灰显并无法点击。
- **内容区**：中间是对话，每段回答上方有一组小标签，显示助手调用过的工具，这些标签可以点击来查看
  工具调用详情；底部是输入框，右侧为 [发送]。
- 窄模式下，在输入框右上角有 [全屏编辑（四角图标）]

**新会话（空会话）**（新账号，新设备，或新建会话进入的页面）中间两行：「你好，我是 CAEventManager 运维助手。」
与「我可以帮你查数据和执行操作。关于平台的问题也可以问我。」。

**打开一段存档对话时**，页面初始化、加载期间居中显示「正在加载对话」，会话名显示为「正在加载…」；
加载完成后会更换成对应的历史消息与标题。无对话内容（新会话）时不出现「正在加载对话」。

「模型设置」点击弹出设置弹窗：接口地址、模型（配置接口地址后，点击右边 [获取模型] 会列出端点返回的可选模型）、
密钥为只写。保存后显示为占位符，不显示实际密钥。
弹窗底部有 [清除密钥]。

输入框左上角外为会话标题。点击可以打开会话选择界面（左侧抽屉），在这里可以改名和删除会话。

输入框右上角外有上下文指示器。悬停或点击可以打开上下文占用详情。

## 模型设置

平台不提供对话模型，使用者需要自行配置。每个账号独立保存模型设置。配置入口在右上角的「模型设置」：

| 项 | 说明 |
| --- | --- |
| 接口地址 | 兼容 OpenAI 的端点，例如 `https://api.deepseek.com`。留空用默认值 (deepseek官方) |
| 模型 | 例如 `deepseek-flash`。留空用默认值 (deepseek-flash)；点「获取模型」会向服务端查询可用模型列表并展示 |
| 密钥 | 只写。留空表示保持现状；清除请点下面的按钮 |

高级设置（点击展开）：
| 项 | 说明 |
| --- | --- |
| 上下文上限 | 单位为token。留空表示由模型名称猜测 |

密钥加密保存在服务器，不经过浏览器，不会进入日志和审计，是平台中为数不多可以干净删除不留痕迹的内容，因为它属于使用者个人的敏感信息，平台仅负保管义务。

## 怎么问

- 使用自然语言直接描述需求，例如「帮我查 2024001 在不在最新的那个名单里」
- 可以打断助手回答。如果助手理解有误，可以追加说明。
- 如果对助手的用词风格不满意，可以直接在提示里说明，例如「请用更口语化的方式回答」。

## 回答是怎样的

- 一轮对话最多来回六步工具调用
- 回答按 Markdown 渲染：分级标题、粗体斜体删除线、引用（可嵌套）、有序无序列表（可嵌套）、
  任务框、表格、分隔线、行内代码与代码块（带语言与复制键）、`<kbd>` 与上下标
- 链接分三种：指向站内文档的写成 `[名单](usage/rosters.md)`（路径与文档清单里的写法一致，
  去掉 `doc/` 前缀），点开在新标签页打开那一篇，后面接 `#标题` 就落在那一节，例如
  `[它会查文档](usage/assistant.md#它会查文档)`；站外地址只认白名单里的站点，目前是
  本项目的 GitHub 仓库与作者主页（见 [关于](about.md)），这些带一枚开新窗口的小箭头、
  点了在新标签页打开，别处只显示文字；指向清单里没有的文档写成红色「链接已断」，点不动。
  图片不渲染，只当文字
- 涉及"现在"的问题它每一轮都重新查一遍，不拿上一轮的结论顶替；这一轮没查成会说没查到
- 回答里不交代过程：读了哪几份文档、调用过哪些工具都不写进去（上方那行小标签已经写着），
  也不括注「取自某文档」「本轮刚读过」这类来源与时序；只读的一轮更不会特意声明
  「没有改动数据」。链接能不能点、要用哪种写法属于平台自己的事，也不会拿来跟你解释
- 回答是流式、实时显示的
- 胶囊会合并同一工具的多次调用（例如「读取活动数据 ×2」）。鼠标悬停在胶囊上（触屏点一下，
  点别处收起）可以查看工具调用参数和结果
- 每段话下提供复制按钮，点击复制该对话原文。复制助手回答时，不包含动作标签、工具结果
- 代码块右上角提供复制按钮，点击复制该代码块原文
- 助手只回答平台范围内的事，超出范围会说清楚

## 它能做什么

以下是助手可以读取的内容。第一列是界面显示的正式工具名称（过程标签内容），括号内是工具名：

| 名称（工具） | 作用 | 谁能用 |
| --- | --- | --- |
| 读取活动列表（`list_events`） | 列出这个账号能看到的活动（含自己在其中的角色） | 所有人 |
| 读取活动数据（`event_board`） | 读一场活动的公示数据：人数、签到、奖票、奖品与最近中奖 | 所有人 |
| 读取名单列表（`list_rosters`） | 列出名单（我参与的 / 我创建的 / 全部） | 所有人 |
| 读取名单成员（`roster_entries`） | 读一份名单里的成员，可按学号或姓名过滤 | 所有人 |
| 读取报名列表（`list_signups`） | 列出报名项：状态、已报人数、名额、写进哪份名单 | 所有人 |
| 读取报名记录（`signup_entries`） | 读一次报名的提交记录 | 所有人 |
| 检索人员（`search_people`） | 在平台人员库里按学号或姓名找人 | 所有人 |
| 读取文档清单（`list_docs`） | 列出随应用装好的说明文档（以及各模块的现场说明） | 所有人 |
| 读取文档（`read_doc`） | 读其中一份文档的正文 | 所有人 |
| 读取审计日志（`recent_audit`） | 最近的审计日志 | 超级管理员及以上 |
| 读取服务器状态（`host_stats`） | 服务器状态与在线人数 | 仅站长 |

## 它也能替你改，但要你点头

以下是助手可以执行的修改操作。第一列是界面显示的正式工具名称（过程标签内容），括号内是工具名：

**这些工具调用时需要用户每次手动确认**。平台不提供自动审批等功能。

| 名称 | 作用 |
| --- | --- |
| 写入名单 | 学号与姓名必填；同一个学号已在名单里就更新分组与备注 |
| 移出名单 | 给学号；同名不止一个时要学号。这是删掉那一条，分组、标签与备注一起丢 |
| 修改报名设置 | 开始与截止时间、名额、开关，只改你说的那几项 |
| 修改活动名称 | — |
| 修改会话标题 | 说「把这段对话改名叫报名排查」就行；它改的是当前这一段的名字 |

这一步是**阻塞**的：助手停在原地等你回答，**没有"已提交、稍后执行"这回事**。

- 点 [批准] 当场执行，结果（成功或失败）交回给助手，它接着把话说完
- 点 [拒绝] 什么都不改；助手就此停手，说明哪一步没做、哪些已经做了、现在是什么状态
- 中间过程用户看不到，只有最后那一句话加几枚动作标签，所以结论要说全
- 这条提示不占对话的位置：上面的历史、输入框里还没发出去的字都不会被动；会话名那条在它上面
- 提示只在这一次有效：换会话、刷新页面、超过五分钟都作废，得重新问一遍
- 走到别的页面去了也不会错过：侧栏「运维助手」上会留一个小红点，会话列表中卡片右上角也有一个；
  回到那段对话，那条提示还在
- 写动作的权限照旧是这个账号自己的：你在页面上做不了的，助手也做不了；
  **需要重新输密码的动作永远不对助手开放**
- 写入实际执行时会追加审计日志。身份标签会标记 `via: assistant` 以区分用户和助手执行的操作。

写动作只走平台自己的接口，助手碰不到服务器上的文件，也读不到文档目录以外的东西。
这五件之外的事，例如发通知、归档名单与活动、改别人的名单，助手会告诉你去哪个页面操作。

## 它会查文档

随应用装好的说明文档它都能读：先 `list_docs` 看清单，再 `read_doc` 读其中一份。问到
「这个页面在哪」「字段什么意思」「怎么备份」「操作台的搜索怎么用」时，它去读对应的一份，
而不是凭印象编。模块自己的说明也在清单里。

读文档是只读、有上限的：一次最多读 12000 字（超出会截断，并附说明）。

文档读取为白名单。助手无法读取不在清单中的文档，也无法读取文档文件夹外的内容。

## 对话存档

- 对话按会话存下来，下次回来接着聊。输入框上方那条是当前会话的名字，点开是会话列表
  （左侧抽屉）：抽屉头上、叉的左边是「新建会话」，每一行右边可以改名、删除；
  导出 Markdown 在页面右上角，**新会话还没有存档，这颗键是灰的**
- 会话 id 在地址里（`.../panel#/assistant/<id>`）：开几个标签页就是几段互不打扰的对话
- 每个账号有一份存档配额（默认 512 KB）。满了不再存新的，页面会提示清理；不够用的人由站长在
  「用户管理」里单独调，那里也能看到某人已经存了多少
- 新会话存下之后会请模型起一个短名字（最多 12 个字）；起不出来就留着第一句话
- **会话名最多 24 个字**，服务端一刀切（手工改名、模型起名都受限）：它要出现在会话条、
  会话卡片与导出的文件名里，太长会把版面挤坏
- 名字只在开头自动起一次。你改过之后就是你的：往后接着聊也不会被冲回第一句话；
  让助手改名字（见上面那张表）也一样，改完这一条上显示的就是新的
- 会话名那一行的右端有一条**上下文用量环**：一条小圆弧表示这段对话占了多少上下文。
  鼠标移上去（触屏点一下）展开明细：已用百分比、`用了多少 / 上限`，以及
  系统提示词、工具说明、对话消息三块各占多少（各带一个色点），再移开（或点外面）收起
- 用量是**估算**的：服务端按字数折算 token（中日韩每字约 0.7 个，其余四个字符一个），
  只用于判断"还剩多少"
- 占用很小的时候不会一律显示 0%：不到 1% 给两位小数、不到 10% 给一位小数，其余取整
- 上限（分母）按模型名取：`deepseek-flash` 与 `deepseek-v4-pro` 是 1000000，其余模型按
  128000。要改在页面右上角「模型设置 › 高级设置」里填「上下文上限」，留空表示由模型决定
- 「模型设置」里的 [清除密钥] 是红色按钮，点它先问一句：清掉之后助手就用不了，要重新填
- 会话流的右下角有一颗圆形 [回到最新]（下箭头）：滚上去了才出现，点一下滑回最底下并自己收起
