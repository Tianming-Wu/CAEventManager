# 管理面板使用说明

面板是所有账号共用的入口：一台服务上装着一批**活动**、一批**名单**与一批**报名**，面板负责账号、
权限、审批，以及把这些东西建起来。

打开服务地址，登录后落在「总览」。

## 账号

- **注册**：`/register` 填登录名、称呼、密码提交，状态是「管理员 · 待审核」——能登录，但看不到
  用户管理、活动管理等只有超级管理员能看的页面。超级管理员或站长审核通过后才进入全部功能
- **登录名**：`[0-9A-Za-z_-]`，3～24 位；`admin`、`root`、`owner`、`support` 这类词是保留词。
  登录名不分大小写地唯一
- **三种角色**：站长（唯一）> 超级管理员 > 管理员。用户管理、活动管理、审批给超级管理员及以上；
  服务器管理与审计日志只给站长
- **敏感操作要重新输一次密码**：改角色、封禁或停用账号、轮换活动访问地址、存档活动。输一次之后
  十分钟内不再问（顶栏会出现「修改模式」标记，可以手动结束）。这条记在会话上：换一台设备登录
  不继承，退出登录立即失效
- **账户信息**：改称呼、登录名、头像、密码；「API 令牌」给平台之外的程序用，见
  [`../reference/api.md`](../reference/api.md)

## 活动

- 「我的活动」列出你是成员的活动；「活动管理」列出全部活动与归档的活动（按角色可见）
- **创建活动**：选一种活动形式（模块），填这一套形式声明的参数，创建后进入活动后台
- **邀请成员**：在活动后台的「活动设置」里按登录名或称呼搜人、发出邀请；对方在自己的
  「我的活动」里确认一次才算加入
- **活动不存在"删除"**：只有存档。存档后它从列表退到「活动管理 › 归档的活动」，
  数据库文件不动，随时可查

## 名单

名单是可以反复用的一批人：社团成员、某次比赛的选手。名单与活动并列，活动从名单里取人。

- **新建 / 导入 / 打开**：「名单与报名 › 我的名单」。导入支持 CSV、TSV 与 **xlsx**：
  - CSV / TSV：第一行可以是表头（学号、姓名、班级、分组、备注）；没有表头按「学号,姓名,班级」读
  - xlsx：只读第一个工作表，第一行当表头；所有单元格按文本读（学号里的前导零不会掉），
    空行跳过，合并单元格只取左上角。公式、图表、多个工作表这些不处理
  - 两种都按学号增量合并：没有的人新增、已有的人更新资料，导入后报告新增几人、名单内已有几人、
    有几行读不了
- **人员是平台级的**：同一个人在多份名单里是同一条人员记录，改一次姓名各处一致。院系与班级分开两列
- **成员可以标成「已退出」而不删**（历史留着），也可以直接移出
- **可见性三档**：私有（只有创建者）、公开（所有登录账号可看）、组织公开（组织建好之前等同公开）
- **写权限是另一件事**：公开名单上谁都能「申请写入权限」，申请后是立刻生效还是等拥有者确认，
  由这份名单自己的设置决定；私有名单只能由拥有者按登录名邀请。拥有者永远可写，也能随时把人移出；
  被授予的人改不了"谁能写"，也不能删名单
- **导出**：「导出 CSV」给 Excel 直接打开（带 BOM），「导出 Excel」给 xlsx。**两种都只有表头与
  数据行**，不加标题、不加说明、不加合计——表格是拿来接着用的，不是拿来当通知的
- **打印名单**：名单详情右上角的「打印名单」（`/print?kind=roster&id=…`）。一张简单的表：
  序号、学号、姓名、院系、班级（有人分组就多一列分组，有已退出的人就多一列状态），
  每页左下角标「第 N / M 页」，换页时表头重复。标题是勾选项，默认不加。
  屏幕上看到的就是印出来的样子：每页按 A4 的可打印区切成一块

## 报名

报名是一条公开链接，报名成功的人直接写进某份名单。

- 「名单与报名 › 我的报名」里创建：名称、说明、**写入哪份名单**、可选的**限制范围**
- **限制范围**默认关闭（拿到链接就能报名）；开启后只有所选名单内的成员能报，学号与姓名都要对上
- **时间**与**名额**各有一个开关。时间开启后开始与结束都能留空：留空表示那一端没有边界；
  名额开启后填上限，满了自动停收
- **重复提交**按学号判断：信息与上次完全一致就提示「您已经报过名」；不一致时看「报名后修改」——
  不允许则提示联系负责人，允许则问「您希望更新信息吗」
- **收集字段**：学号与姓名固定必填；院系与班级各由复选框决定收不收；其余字段自己加（单行文本、
  多行文本、数字、单选、日期，可标必填），每个字段选一个去向：只留在本次报名、写入院系、写入班级、
  写成名单里的分组、写成名单里的备注
- **视觉效果**：四档主题（素色 / 暖色 / 冷色 / 暗色）配一个主色，右侧即时预览
- 公开页地址是 `/join/<报名 token>`，不需要登录；提交记录在报名详情里查
- **导出**：「导出报名表」是 CSV，「导出 Excel」是 xlsx；两样都只有表头与数据行
- **打印报名表**：报名详情右上角的「打印报名表」另开一张纸（`/print?kind=signup&id=…`）。
  默认就是**已报名单**：一张只有学号、姓名、院系、班级与自定义字段的表，每页左下角标
  「第 N / M 页」。标题与二维码各有一个勾选框，默认都不加。「空白表」留在切换里备选
  （行数可调），但实际更常用的是在线报名。打印时工具栏自动消失，纸永远是白底黑字
- 谁能看这份报名，谁才能打印它的报名表：打印页读的是面板自己的接口

## 审批

- **待审核的用户**：新注册的账号在这里通过或拒绝
- **活跃审批**：名单写入权限的申请集中在这里

## 预设

预设是**一份存下来的活动配置**：用哪个模块、那套参数、建议的活动名称。它不是配置项清单，
而是某场活动当时的设定快照。

- 在活动卡片菜单里「保存为预设」，下次建活动时挑一份，改改名称和人数就能开下一场
- 三处陈列：我收藏的、我创建的、预设广场。可见性三档：私有 / 公开 / 组织公开（目前按公开处理）
- 模块是能力边界，预设是边界之内的一个练好的配置：停用模块不能再拿它开新活动，
  已开的活动与它们的预设照旧可读

## 服务器管理与审计日志

站长可见。服务器管理显示这台机器的占用、在线人数与版本；审计日志记每一次写入——谁、什么时候、
对哪个对象、改了什么。分页读取，搜索在服务端完成。

## 手机上

面板在手机上同样能用：侧栏收成抽屉，表格在放不下时横向滚动（首列与操作列贴边，
首列自己被内容撑得过大半屏时改为一起滚），日期与时刻换成系统选择器。
