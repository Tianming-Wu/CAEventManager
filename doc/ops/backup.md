# 备份 - 自动备份、异地副本与恢复

站长可在「服务器管理」的「备份」卡片查看备份状态。点击标题栏的 [立即备份] 可创建本地备份。手动备份不会上传 WebDAV 副本或执行留存清理。

## 调整设置

点击卡片标题栏的 [设置]，调整自动备份、调度方式、触发时刻和留存范围。选择「手动」时，仅按需创建备份。触发时刻采用服务器本地时间。设置的默认值和留存规则见[部署与运维](deploy.md#自动备份)。

需要异地副本时，展开「WebDAV（异地副本）」，打开 [启用] 并填写连接信息。修改其他设置时，可将「密码」留空以保留已保存的密码。点击 [保存设置] 并通过 [sudo 模式](../usage/sudo.md)确认，再点击 [测试 WebDAV] 检查已保存的连接设置。

自动备份完成后会上传副本。上传失败时保留本地备份。手动备份失败、自动备份失败或异地副本处理失败时，站长可在顶栏的 [通知（铃铛图标）] 查看提示。

## 查看和校验备份

卡片显示最近一次备份时间和自检结果，表格列出最近 5 份备份。文件名前的绿色圆点表示备份清单可读取，红色圆点表示无法读取清单。恢复前请按[备份与恢复](deploy.md#备份与恢复)的步骤完整校验备份。也可通过命令行查看更早的备份。

## 恢复

先停止服务，再按[备份与恢复](deploy.md#备份与恢复)执行恢复。系统会在恢复前保存当前数据，生成一份种类为「恢复前」的备份。
