# 组织 - 归属关系与组织内身份

侧栏「组织管理」，只对超级管理员及以上开放。

组织记录的是一份归属：谁属于哪个组织，在其中是什么身份。组织内的身份不带来平台权限，不能修改账号角色、重置密码或删除账号。活动暂不挂在组织上。

## 组织列表

侧栏「组织管理」。

内容区一张组织表：列为 名称 / 标识 / 成员 / 我的身份 / 状态 / 操作；成员列同时写出总负责人人数，例如「12（总负责人 2）」。表头右侧是搜索框，可按组织名称或标识搜索。列表上方写着「共 N 个组织」，搜索时同时显示匹配数量。

点击页面右上角的 [创建组织]，进入「组织管理 › 创建组织」页面。

## 创建组织

「创建组织」页面依次填写以下内容：

| 字段 | 说明 |
| --- | --- |
| 名称 | 必填，最长 40 个字 |
| 组织标识 | 必填，3 到 24 位小写字母、数字、连字符与下划线，例如 `cs-club`。建好后不可更改 |
| 说明 | 选填，最长 200 个字 |
| 总负责人 | 必填，至少一位，可以有多位 |
| 组织管理 / 成员 | 选填，可以之后再添加 |

点击 [总负责人]、[组织管理] 或 [成员] 右侧的加号进入选人弹窗，勾选后按 [完成]。已在其中一个框中选定的人，不会再出现在另外两个框里；要移到另一个身份，先在这个框里点击头像右侧的 ×，再在另一个框里重新选。总负责人是单选弹窗，选一位后按 [完成] 替换原来那一位。

填写完成后点击页面右上角的 [创建组织]。组织创建后回到「组织管理」，新组织出现在列表里。

## 组织内身份

| 身份 | 列表中的写法 |
| --- | --- |
| 总负责人 | 总负责人 |
| 组织管理 | 组织管理 |
| 组织成员 | 组织成员 |

每个组织至少要保留一位总负责人。

组织内的身份目前只在「组织管理」的列表里查看。

## 归档与彻底删除

组织不再使用时点击操作列的 [归档]，确认后归档。归档把成员关系折进组织那一行存放，明细行随之删除；组织仍留在列表里，状态标为「已归档」，成员数与总负责人人数照旧显示。归档的组织不能再改名称或成员，操作列只保留 [恢复] 与 [彻底删除]。

点击 [恢复] 展开成员关系，组织回到正常状态。

[彻底删除] 只对已归档的组织出现，只对站长可见，并且须进入 [sudo 模式](sudo.md)。删除后不能恢复，成员的归属记录一并消失。

## 导入账号中的组织

批量导入账号的「组织」列目前是预留字段，导入时不会写入组织归属。参见[导入账号](account-import.md)。
