# 平台管理页 - 用户管理、模块管理与展示屏幕

这三页的管理功能只对超级管理员及以上开放；站长另有审计日志与服务器管理，见 [server.md](server.md)。

## 用户管理

侧栏「用户管理」。内容区一张账号表：列是 用户名 / 称呼 / 角色 / 状态 / 最近登录 / 操作；
表头右侧是搜索框，列表底部 [加载更多]。

每行的操作列可以改角色、封禁或停用、重置密码、[调整存档配额]（助手对话的存档上限）。
待审核的账号不在这里批，在「活跃审批 › 注册申请」。

## 模块管理

侧栏「模块管理」，只有站长能看到。内容区一张表：模块 / 版本 / 作者 / 状态。

- 停用的模块不再出现在创建活动的列表里，已经开出来的活动照旧可读
- 装新模块是把目录放进 `modules/`，重启后出现在这张表里

## 展示屏幕

侧栏「外部资源 › 展示屏幕」。页面右上角 [导入]；内容区三块：可用的屏幕、导入说明、引用方式。

- 「可用的屏幕」列出内置与导入的展示屏幕，各自有标识与体积
- 「导入说明」写着导入要求：包内要有 `screen.html`，只收样式表、脚本与图片，压缩包 2 MB 以内、
  解开后 8 MB 以内
- 活动用哪一份屏幕，在活动后台的「活动设置」里选
