# 开始使用 - 注册、审核与面板导航

打开服务地址即登录页，注册入口是 `/register`。

## 登录页

输入登录名及密码，点击 [登录]。表单内可以使用上下方向键在输入框之间移动。多行文本、下拉框、数字和日期时间输入框保留方向键的原有功能。

## 总览页

「总览」显示我的活动、我的名单、我的报名和待处理邀请的数量，以及「最近操作」。账号总数、待审核申请和「审计日志」入口按账号权限显示。

## 注册与审核

在注册页面填写登录名、显示名与密码并提交申请。申请获批后可登录。参见[注册申请](approval.md#注册申请)。

超级管理员和站长也可直接创建账号。参见[用户管理](platform-pages.md#用户管理)。账号数量达到上限时，平台停止接收新注册申请。

忘记密码时，请联系超级管理员或站长。参见[重置密码](platform-pages.md#重置密码)。

## 侧栏

从上到下：

| 分组 | 页 |
| --- | --- |
| — | 总览、运维助手、我的活动、预设管理 |
| 名单与报名 | 我的名单、我的报名、写入审批 |
| 外部资源 | 展示屏幕 |
| — | 用户管理、活动管理、名单管理、组织管理（超级管理员及以上） |
| 活跃审批 | 注册申请、活动申请（超级管理员及以上） |
| — | 服务器管理、模块管理、审计日志（仅站长） |

侧栏底部提供「界面设置」。点击账号卡片可进入「账户信息」。

当前页面所在的栏目淡一档高亮，例如打开「组织管理 › 创建组织」时，「组织管理」保持淡高亮，点击它回到该栏目。当前页面本身为实高亮。

## 顶栏

顶栏左侧显示产品名称与版本号，站长还可查看服务资源占用情况。右侧为 [通知]。

有未读通知时，通知图标显示圆点。参见[通知与服务提示](notices.md)。

## 宽屏与窄屏

布局随窗口宽度变化：

- **大于 1100px**：侧栏固定于左侧，显示图标与文字
- **761～1100px**：侧栏仅显示图标，点击分组图标可展开子项
- **760px 及以下**：侧栏默认收起，顶栏左侧出现 [打开导航（三条横线图标）]，
  点击后展开侧栏，内容区采用单列布局

窄屏下表格横向滚动（第一列与操作列固定），日期与时刻改用系统选择器。
