# 账号与角色 - 三种身份与账户信息

## 页面结构

「账户信息」一页由三张卡片组成：

- 「个人资料」：可修改头像（[更换头像]）、显示名、登录名、
  密码，每处一个 [保存]
- 「API 令牌」：我的令牌列表，副标题「供外部程序访问平台接口」，
  卡片标题栏右侧 [新建令牌]；每行可吊销
- 「安全」：一个 [退出登录]

## 三种角色

| 角色 | 能力 |
| --- | --- |
| 站长 | 除全部管理功能外，额外有「服务器管理」「模块管理」「审计日志」 |
| 超级管理员 | 用户管理、活动管理、活跃审批、展示屏幕（静态资源） |
| 管理员 | 自己的活动、自己的名单与报名、预设、运维助手 |

平台账号需要在注册页面填写信息注册，经过超级管理员或站长审核通过后才能登录。
默认注册的账号是管理员角色。站长可以设置账号的角色。

账号可以被停用、封禁或永久删除。停用或封禁的账号无法登录，永久删除的账号无法恢复。

## 登录名

`[0-9A-Za-z_-]`，3～24 位；`admin`、`root`、`owner`、`support` 这类词是保留词，不能注册。
登录名不分大小写唯一，修改之后旧登录名立刻失效。

登录名是登录用的凭据，其他账号通常只能看到显示名。

## 账号编号

账号唯一标识符，不可更改，不可复用。显示于「用户管理」中账号详情的「编号」一列，形如 `#10001`。
站长账号编号为 `#10000`。其他账号按创建顺序获得编号。

- 账号删除后，原编号不再分配。
- 编号与登录名无关。修改登录名、显示名都不会改变编号。

## 账户信息

点击侧栏底部的账号卡片，打开「账户信息」页面。这里可以更改登录名、显示名、头像与密码。

- 显示名用于成员列表、审计日志等界面。未填写时显示账号编号
- 修改密码时须输入旧密码，新密码至少 8 位。修改后，其他登录会话失效，当前会话和 API 令牌继续有效
- 忘记密码时，请联系站长或超级管理员。参见[重置密码](platform-pages.md#重置密码)
- 使用临时密码登录后，须先在「重设密码」页面设置新密码。参见[临时密码](platform-pages.md#临时密码)。

## API 令牌

在「账户信息」的「API 令牌」中管理令牌。参见 [API 令牌](../reference/api-tokens.md)。
