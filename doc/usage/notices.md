# 通知与服务提示 - 查看通知和服务状态

点击顶栏右侧的 [通知] 打开通知中心。铃铛图标上的圆点表示有未读通知。

## 通知

打开单条通知时，该通知标记为已读。点击底部的 [全部已读] 可将所有通知标记为已读。

未读的紧急通知在登录后单独显示。点击 [已读] 可确认通知。点击 [关闭] 会保留未读状态，下次登录时仍会显示。

## 服务提示

服务状态异常时，通知图标以强调色显示，提示位于通知列表顶部。活动后台右上角也会显示服务提示，悬停可查看详情。

| 情况 | 提示处理 |
| --- | --- |
| CPU 或内存占用偏高 | 占用恢复正常后自动消失 |
| 数据盘空间不足 | 可选择 [不再提示]，释放足够空间后自动消失 |
| 数据盘空间即将用尽 | 释放足够空间后自动消失 |
