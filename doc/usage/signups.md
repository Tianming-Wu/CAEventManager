# 报名 - 链接、限制、字段与二维码

报名是一条公开链接：报名成功的人直接写入绑定的名单。

入口为「名单与报名 › 我的报名」。

## 页面结构

- **我的报名**：页面右上角 [创建报名]；列表底部 [加载更多]
- **报名详情**：页面标题是面包屑，左边一个 [返回（左箭头图标）]；页面右上角依次 [保存设置]
  [下载二维码] [导出报名表] [导出 Excel] [打印报名表] [归档报名]，[下载二维码] 右边是
  [更多格式（三个点图标）]；内容区卡片为 公开链接、基本信息、时间、名额、收集字段、视觉效果、
  报名、提交记录
- **公开报名页**显示报名说明、表单及提交按钮。报名人员无需登录

## 归档

在报名详情点击 [归档报名] 并确认。归档后，报名从「我的报名」移除，公开链接失效，已提交的记录保留。取消归档与彻底删除参见[名单管理](platform-pages.md#名单管理)。

## 创建

在「我的报名」点击 [创建报名]，填写名称与说明，选择接收报名记录的名单。创建成功后进入报名详情页。

在报名详情页可以获取报名的链接和二维码。

在报名详情的「提交记录」中查看报名资料。

## 限制范围

默认关闭，持有公开链接的人员均可报名。

开启后只有所选名单内成员可以报名，学号与姓名需要同时匹配。

## 时间与名额

各有一个开关：

- **时间**：开始时间与结束时间均可留空，对应的时间限制将不生效
- **名额**：填写名额上限，达到上限后停止接收报名

## 重复提交

按学号判断。信息与上次提交一致时提示「您已经报过名」；信息不一致时，按「报名后修改」设置处理。

- 不允许：提示联系负责人
- 允许：问「您希望更新信息吗」

## 收集字段

学号与姓名固定必填。院系与班级各由一个复选框启用。

可添加单行文本、多行文本、数字、单选、日期，可分别设为必填，并选择字段资料的保存位置。

- 只留在本次报名
- 写入院系
- 写入班级
- 写成名单里的分组
- 写成名单里的备注

## 视觉效果

选择主题（素色、暖色、冷色或暗色）与主色，可在右侧即时预览。

## 二维码

扫描二维码可打开报名页。可在报名详情通过 [下载二维码] 或其右侧的 [更多格式] 选择下载格式。

| 格式 | 用途 |
| --- | --- |
| `PNG · 1 格 1 像素，无留白` | 无边距黑白图像，适合嵌入文档或重新排版 |
| `PNG · 1024，带留白` | 打印与张贴，四周留四个模块的白边，便于扫描 |
| `SVG · 矢量` | 适合缩放和排版 |

## 关于短链

长期使用的报名入口应引用报名详情中的公开链接。参见[短链](shortlinks.md)。
