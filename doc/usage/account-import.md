# 导入账号 - 批量创建账号并分发初始密码

仅站长可在「用户管理」页面右上角，点击 [新建账号] 左侧的 [导入账号]，进入「用户管理 › 导入账号」页面。

## 录入账号资料

在「导入表」中点击 [选择文件]，上传 CSV 或 Excel（`.xlsx`、`.xlsm`）文件。也可点击 [手动录入]，在预览表中添加一行并填写资料。

| 表头 | 说明 |
| --- | --- |
| 登录名 | 可留空，之后使用 [自动填充] 生成 |
| 显示名 | 必填 |
| 角色 | 可选管理员或超级管理员，默认为管理员。参见[账号与角色](account.md) |
| 初始密码 | 可留空，之后使用 [自动填充] 生成 |
| 组织 | 预留字段，目前不生效 |
| 备注 | 选填 |

文件中的其他列可供密码规则引用，例如「学号」。

## 自动填充

点击 [自动填充]，按需启用「补齐登录名（按姓名拼音）」或「补齐初始密码」。启用「补齐初始密码」时，在「密码规则」中选择生成方式。设置完成后，点击弹窗中的 [自动填充]。

登录名按显示名的拼音生成，遇到重名时自动追加序号。自动填充仅处理当前空白的登录名和初始密码。后续清空字段时，可再次使用 [自动填充]。

| 密码规则 | 生成方式 |
| --- | --- |
| 随机 12 位 | 生成 12 位随机字符，排除 0、O、1、l、I 等易混淆字符 |
| 学号原样（不足 8 位补随机） | 使用「学号」列的完整值 |
| 学号后六位 | 取「学号」列的末六位 |
| 姓名拼音加四位随机 | 在显示名的拼音后追加四位随机字符，例如 `zhangsanK7m2` |
| 自定义规则 | 在出现的「自定义规则」输入框中填写规则 |

自定义规则可使用 `{{列名}}` 引用列值，或使用 `{{学号:6}}` 取「学号」列的末六位。可引用文件中的列，也可使用「登录名」「显示名」「角色」「备注」。引用的值为空时，请补充相应资料或更换密码规则。按规则生成的密码不足八位时，自动补充随机字符至八位。

## 核对并导入

1. 在预览表中核对并按需修改登录名、显示名、角色、初始密码和备注。无法导入的行以红色标示，将鼠标指针停在行末的感叹号上可查看原因。全部记录通过校验且创建数量未超出账号上限时，[导入] 可用。
2. 点击 [下载账号表]，保存包含当前预览内容及初始密码的 CSV 文件。修改预览后，请重新下载。
3. 点击 [导入]。如果当前预览尚未下载，系统会提示「尚未下载账号表」。可返回下载，或点击 [仍然导入]。导入后无法再次查看未下载的更改。

将初始密码分别交给对应的账号使用者。使用者首次登录时须先设置新密码，随后方可使用其他功能。

## 离开页面

导入前返回「用户管理」或切换页面时，如果预览中仍有记录，系统会提示「离开导入账号？」。点击 [继续编辑] 可保留当前预览，点击 [离开] 将清除预览及其中的初始密码。
