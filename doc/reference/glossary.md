# 术语表 - 界面、文档与代码共用的词

界面、文档与代码注释使用下列术语。

## 主体

| 术语 | 定义 | 避免使用 |
| --- | --- | --- |
| 活动 | 平台中可独立管理的活动，具体页面和功能由模块提供 | 场次、event（界面上） |
| 名单 | 可重复使用的人员集合，例如社团成员或参赛人员 | 名册、名簿 |
| 报名 | 通过公开链接收集资料，并将报名记录写入关联名单 | 招募、登记表 |
| 人员 | 平台管理的人员，同一人员可出现在多份名单中 | 学生、用户（指人时） |
| 成员 | 加入名单或活动的人员。活动中的成员权限取决于席位 | 参与者（那是另一回事） |
| 预设 | 可用于创建活动的配置，包括模块、参数和建议名称 | 模板 |
| 模块 | 定义活动形式、业务能力与页面的组件 | 插件 |
| 高危权限 | 模块声明的特殊权限，可涉及跨活动、跨账号或外部跳转。导入模块时显示权限清单 | 高级权限、管理员权限 |
| 导入模块 | 站长在「模块管理」上传并确认安装模块 ZIP 包的操作 | 安装插件、上传代码 |
| 账号 | 登录面板的身份 | 用户 |
| 账号编号 | 账号的唯一对外标识，例如 `#10001` | 用户名、登录名 |
| 短链 | 平台生成的临时跳转地址，形如 `/s/AB3D7KM`，属于活动的平台资产 | 短网址、外链 |
| 提权操作 | 需要通过 [sudo 模式](../usage/sudo.md) 执行的操作，通常涉及不可撤销的修改或代其他账号管理数据 | 越权操作 |
| 归档 | 从拥有者的列表移除对象并保留资料。归档后的管理入口参见[平台管理页](../usage/platform-pages.md) | 删除、停用 |
| 彻底删除 | 永久移除数据。对象的适用条件参见[平台管理页](../usage/platform-pages.md) | 清空、移除 |
| 静态设置 | 保存在 `config.json` 中、修改后须重启服务的设置 | 静态配置、环境变量 |
| 设置 | 可调整的功能参数，例如活动设置和平台设置 | 配置项 |

## 角色

| 词 | 能力 |
| --- | --- |
| 站长 | 唯一。全部权限，含服务器管理与审计日志 |
| 超级管理员 | 账号、活动、审批、外部资源 |
| 管理员 | 自己的活动、名单、报名、助手 |

活动席位包括负责人和成员，成员状态见下表。角色和入口参见[账号与角色](../usage/account.md)。

## 状态词

| 场景 | 取值 |
| --- | --- |
| 活动 | 未开始 / 进行中 / 已结束 |
| 报名 | 未开始 / 进行中 / 已结束 / 已满 / 已禁用 / 已归档 |
| 名额 | 不限 / 剩余 N |
| 名单成员 | 在册 / 已退出 |
| 活动成员 | 待确认 / 在册 / 已移出 |
| 账号 | 待审核 / 正常 / 已停用 / 已拒绝 / 已封禁 |
| 名单可见性 | 私有 / 公开 / 组织公开 |

## 现场

| 术语 | 定义 |
| --- | --- |
| 签到 | 登记到场状态。签到方式由活动所用模块决定 |
| 任务一 / 任务二 | 任务链的两环：签到 → 任务一 → 任务二 |
| 越序 | 在前置环节尚未完成时标记后续环节。须解锁修改，操作会记录到日志 |
| 奖票 / 票号 | 用于抽奖的凭证及其编号 |
| 保底票 | 符合模块规则的人员可获得的基础奖票 |
| 抽奖池 | 可抽的票的集合，按池子模式计算 |
| 逐个 / 一次抽完 | 奖品的抽取节奏 |
| 公示页 | 只读的对外页面 |
| 大屏 | 投影页 |
| 操作台 | 用于现场操作的活动后台页面 |

## 文档与代码里的固定说法

- 中文界面用「创建」，不用「申请」；「申请」只留给权限申请
- 按钮用动词：保存 / 创建 / 导入 / 移出 / 授予写入权限 / 清除密钥
- 空状态：还没有…；没有匹配的…
- 分页按钮：再显示 N 条
