# 预设 - 保存并复用活动配置

预设包含活动所用模块、配置参数和建议的活动名称。创建活动时可选择预设并调整适用的设置。

## 预设管理

「预设管理」列出「我收藏的预设」「我创建的预设」和「预设广场」。页面右上角提供 [导入预设] 和 [新建预设]。

可见性分为私有、公开与组织公开。私有预设仅创建者可见，公开预设对登录账号可见。目前组织公开与公开的可见范围相同。

## 从活动保存预设

在「我的活动」打开活动卡片的 [更多] 菜单，选择 [保存为预设]。模块停用期间，其预设无法用于创建活动。
