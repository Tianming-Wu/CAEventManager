# 活动 - 创建活动、管理成员与归档

模块决定活动可用的页面与设置。在侧栏打开「我的活动」，可查看「待处理的邀请」「我创建的活动」和「我参与的活动」。点击活动卡片上的 [管理面板] 进入活动后台。

## 创建活动

点击「我的活动」右上角的 [创建活动]，选择活动形式并填写创建所需的设置。可选择已有预设，或点击 [导入配置]。创建后，当前账号成为负责人，活动后台在新标签页打开。

## 邀请成员

可在「创建活动」的「成员」卡片，或在活动后台的「活动设置 › 成员」发出邀请。受邀账号在「我的活动 › 待处理的邀请」确认后成为成员。接受前可撤回邀请。

移出成员后，其状态变为「已移出」，可重新邀请。负责人无法移出自己或活动中唯一的负责人。转移负责人参见[活动管理](platform-pages.md#活动管理)。

## 下载数据

活动开放期间，负责人和成员可在活动详情点击 [下载数据] 保存 ZIP 文件。需要保留活动资料时，请在归档前下载。

## 归档

负责人执行 [归档] 并确认后，活动从「我的活动」移除，活动短链失效。取消归档后，原短链仍不可用。取消归档、下载完整数据和彻底删除参见[活动管理](platform-pages.md#活动管理)。
