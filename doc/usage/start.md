# 开始用

打开服务地址就是登录页（`/register` 是注册）。登录之后落在「总览」。

## 注册与审核

自己填登录名、称呼、密码提交，账号状态是「管理员 · 待审核」：这时已经能登录，但看不到用户管理与
活动管理。超级管理员或站长在「活跃审批 › 注册申请」里通过之后，才进入全部功能。

忘记密码找站长重置。

## 侧栏

从上到下：

| 分组 | 页 |
| --- | --- |
| — | 总览、运维助手、我的活动、预设管理 |
| 名单与报名 | 我的名单、我的报名、写入审批 |
| 外部资源 | 展示屏幕 |
| — | 用户管理、活动管理（超级管理员及以上） |
| 活跃审批 | 注册申请、活动申请（超级管理员及以上） |
| — | 服务器管理、模块管理、审计日志（仅站长） |

最下面是「界面设置」与自己的账号卡片，点卡片进「账户信息」。

看不全是对的：看不到的页与这个角色无关。

## 顶栏

左边是产品名与版本号，站长这里还多一条机器占用；右边是通知。

新的通知进来时铃铛上出现圆点。点开是通知中心，别人发的通知与服务降级提示都在里面，
见 [`notices.md`](notices.md)。

## 手机上

面板在手机上同样能用：侧栏收成抽屉，表格在放不下时横向滚动（首列与操作列贴边，
首列自己被内容撑得过大半屏时改为一起滚），日期与时刻换成系统选择器。
