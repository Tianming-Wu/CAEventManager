# 账号与角色 - 三种身份与账户信息

## 页面结构

「账户信息」一页由三张卡片组成：

- 「个人资料」：页面副标题写「你自己的账号」。卡片里是头像（[更换头像]）、显示名、登录名、
  密码，每处一个 [保存]
- 「API 令牌」：我的令牌列表，副标题「给平台之外的程序使用，例如脚本与群机器人」，
  卡片标题栏右侧 [新建令牌]；每行可吊销
- 「安全」：一个 [退出登录]

## 三种角色

| 角色 | 能力 |
| --- | --- |
| 站长 | 除全部管理功能外，额外有「服务器管理」「模块管理」「审计日志」 |
| 超级管理员 | 用户管理、活动管理、活跃审批、展示屏幕（静态资源） |
| 管理员 | 自己的活动、自己的名单与报名、预设、运维助手 |

平台账号需要在注册页面填写信息注册，经过超级管理员或站长审核通过后才能登陆。
默认注册的账号是管理员角色。站长可以设置账户的角色。

账号可以被停用、封禁或永久删除。停用或封禁的账号无法登录，永久删除的账号无法恢复。

## 登录名

`[0-9A-Za-z_-]`，3～24 位；`admin`、`root`、`owner`、`support` 这类词是保留词，不能注册。
登录名不分大小写唯一，修改之后旧登录名立刻失效。

登录名是登录用的凭据，不积极出现在其他人的界面上。其他人看到的通常是“显示名”。

## 账号编号

账号唯一标识符，不可更改，不可复用。显示于「用户管理」中账号详情的「编号」一列，形如 `#10001`。
站长固定为 `#10000`。其余用户以注册时间顺序分配，最大为 `4294967295`。

- 编号一次性发放，**不再回收**：即使账号被删除，留下的空号也不会分给之后注册的用户。
- 编号与登录名无关。修改登录名、显示名都不会改变编号。
- 对外说明「是哪一个人」时用编号，不用登录名

## 账户信息

侧栏置底位置为自己的账号卡片。点击可以打开「账户信息」页面。这里可以更改登录名、显示名、头像与密码。

- 显示名是别人在成员列表、审计日志里可见的名字；未填写则显示为账号编号，而不是登录名
- 改密码需要输入旧密码，新密码至少 8 位。改完之后**别处的登录会被踢下线**，
  正在改的这一台不受影响；自己的 API 令牌不动
- 忘了密码**自己改不了**（改密码要先输旧密码）：找站长或超级管理员在「用户管理」里重置，
  见 [平台管理页](platform-pages.md#重置密码)。那种重置会把会话与令牌一起作废
- **账号是管理员开的、或密码被管理员重置过**时，会处在「临时密码」状态：用那串临时密码登录后
  直接落在「重设密码」那一页，只有新密码与再次输入新密码两格，不要旧密码；改完才能进面板

## API 令牌

给平台之外的程序用，例如脚本、群机器人。入口也在「账户信息」，一人一张或多张。
怎么建、三档范围、以及它做不到什么，见 [../reference/api-tokens.md](../reference/api-tokens.md)。
**三档范围至少要勾一项**：一项都没有的令牌什么也读不到，所以创建键是灰的，
左下角会显示「无法创建空权限令牌」。
