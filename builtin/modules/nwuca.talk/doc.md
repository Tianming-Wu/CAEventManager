# 讲座 - 按议程推进的分享会

用于管理讲座的议程、现场提问与大屏展示。

## 模块信息

| 项目 | 内容 |
| --- | --- |
| 名称 | 讲座 |
| 模块 ID | `nwuca.talk` |
| 提供方式 | 内置 |

## 页签

在活动后台使用以下页签。

- **议程**：按顺序列出小节，[开始] 记录小节的开始时间并结束上一节。点击 [结束当前小节] 结束正在进行的小节。可添加小节并填写标题及计划时长。删除小节要打开右上角的「解锁修改」
- **提问**：记录现场提问，提问人可留空。回答后点击 [已回答]；删除提问同样要解锁
- **设置**：设置大屏是否显示提问

顶栏的状态条显示：几节已完成、正在讲哪一节、多少条待回答。

## 大屏

大屏显示当前小节、已完成的小节数量及待回答的提问数量。

## 导出

活动设置里的「下载数据」会打包两张表：`01-议程.csv`（每节的计划时长与实际开始/结束时间）、
`02-提问.csv`（提问人、提问内容与回答状态）。「仅名单 CSV」在这个模块里给的是议程那张。
