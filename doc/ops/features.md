# 服务器特性 - 查看可选能力及其状态

站长可在「服务器管理」的「服务器特性」卡片查看可选能力。绿色圆点表示可用，红色圆点表示不可用，具体原因见「状态」列。

## 自动图片缩放

启用此特性后，服务器可按页面需要缩放站内上传的组织外观图。缺少 Pillow 时，页面仍可显示已有尺寸的图片，但可能需要加载较大的图片。安装步骤见[可选依赖](deploy.md#可选依赖)。安装并重启后，「自动图片缩放」的状态列会显示 Pillow 版本。
