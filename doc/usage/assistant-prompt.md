# 助手的平台提示词 - 文件位置、变量与例子

平台为助手生成一套固定的提示词，指导助手的表述和行为。除此之外，部署实例可以附加一份自己的
要求：显示名、语气、固定说法。这段写在服务端的一份 markdown 里，由部署者手工维护。

位置：`<数据目录>/assistant_prompt.md`

- 内容是**追加**在固定提示词之后发送的，无需包含常规操作指示等内容
- 提示词按修改时间缓存：存盘后**下一条消息**会自动注入新内容，无需重启服务
- 附加提示词上限 20 KB，超出会被截断。**不建议**使用过长的提示词，因为：
  - 过长的提示词会占用模型的上下文长度，影响对话质量
  - 过长的提示词会增加网络传输量，影响响应速度
- 可以使用环境变量 `LOTTERY_ASSISTANT_PROMPT` 指向自定义提示词文件路径
- 提示词文件为只读。系统不会写入，界面上也没有编辑入口。请在部署实例中手工维护。

## 可用变量

提示词支持变量系统，可以包含以下占位符。发送时会按照当前实际情况替换。

| 占位符 | 替换内容 |
| --- | --- |
| `${user.username}` | 用户登录名 |
| `${user.name}` | 用户显示名（未填写则则为登录名） |
| `${user.role}` | 身份：站长 / 超级管理员 / 管理员 |
| `${user.roleKey}` | `owner` / `superadmin` / `admin`（想按身份分头交代时用） |
| `${user.id}` | 当前账号 id |
| `${panel.name}` | "CAEventManager" |
| `${panel.version}` | 平台版本号，例如 `1.7.0.32` |
| `${tools}` | 这个账号权限内可用的工具名，顿号分隔 |
| `${time.date}` | 日期，形如 2026-11-07 |
| `${time.time}` | 时间，形如 20:42 |
| `${time.now}` | 时间戳，形如 2026-11-07 20:42 |

无法识别的占位符会被**原样保留**而不是替换为空白内容。

## 温馨提示

**强烈不建议**在提示词内包含任何以下内容：

- 密钥、密码、令牌：凭据不应进入提示词。
- 其他部署实例才需要知道的内容：提示词会发给模型端点，写进去就等于发出去
- 回答的 Markdown 语法与站内文档链接写法已经包含在平台固定提示词内。在自定义提示词中包含 Markdown
输出规则可能造成冲突，导致助手无法正确理解，进而无法正确按要求格式回答。如果您需要编写 Markdown 输出
规则指示，请确保您已充分阅读并理解平台的 Markdown 支持程度。

## 风险警告

1. 使用自定义提示词有模型安全注入和信息泄露风险。请确保提示词内容不会泄露敏感信息，也不会引导模型执行危险操作。
2. 平台无法控制用户使用的模型端点。请注意模型 API 会实际接收到任何发送给助手的内容，因此使用未知第三方端点
有可能导致提示词内容被泄露。请勿在提示词中包含任何敏感信息，包括现实人员的身份信息、联系方式等。
