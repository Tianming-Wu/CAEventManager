# 界面规范 - 管理面板与活动后台

面板与活动后台使用统一的布局、控件与反馈规则。界面术语及文档中的位置名称见[界面描述写法](../reference/ui-naming.md)。

## 页面标题与返回

页面以 `<header class="page-head">` 开始，包含页面标题、可选副标题和右上角主操作 `.page-actions`。标题区高度及正文起始位置在各页面保持一致。按钮的上下外边距与 `.page-head` 的最小高度共同约束布局，相关测试为 `head_align`。

路由表中的 `parent` 提供默认返回地址及面包屑名称。详情页左上角显示宽 34px 的圆角返回图标，标题只显示上级与当前两段。查询参数 `?back=` 可覆盖返回地址。无 `parent` 的页面仅在有 `?back=` 时显示返回图标，此时标题仍只显示当前页面名称。

切换页面时，返回图标的可见性发生变化才播放动画。`.head-title` 通过 `padding-left` 在 0 与 36px 之间过渡。页面内容完成更新后，由 `PX.afterApi` 和 `requestIdleCallback` 调度过渡。返回图标保持在标题区左侧。相关测试为 `crumb_motion`，逐帧检查标题与副标题位置，标题单帧位移不超过 6px，二者单帧位移差不超过 1.5px。

## 卡片与表格

- 内容区以 `.card` 组织，卡片间距为 14px。双列布局使用 `.cols-2 > .col`，各列独立排列，列底对齐。
- `.card-head` 左侧放置 `h2` 或状态信息，右侧放置搜索框及操作按钮。卡片标题栏控件的最小高度为 34px，字段间距为 12px。
- 表格使用 `<table class="tbl fixed">`，按表格约束列宽。对象名称放在首列，数字列右对齐并使用 `.num`，时间列使用 `.mono` 和 `PX.whenExact`。
- 操作列位于最右侧，使用 `.actions`。同一单元格中相邻按钮间距为 6px。
- 列表使用 `markLoading(key)`、`markLoaded(key)` 与 `rowsOrEmpty()` 区分加载和空结果。加载时显示「正在读取…」，无内容时使用「还没有…」或「没有匹配的…」。
- 分页按钮置于表格下方，按对象使用「再显示 N 条」等文案。窄布局使用 `.tblwrap` 提供横向滚动，表格最小宽度为 640px，首列和操作列分别固定在两侧。

## 表单与控件

- 表单字段使用 `.field` 包含标签、输入控件及可选 `.hint`。在字段下方或表单错误区域显示校验失败原因。
- 面板日期和时刻分别使用文本框，格式为 `yyyy-mm-dd` 和 `HH:MM`，提供选择和清除操作。宽度不超过 760px 时使用原生日期和时刻选择器，所选值同步到共用表单字段。
- 开关使用 `.switch`。卡片标题栏的图形开关使用 `title` 和 `aria-label` 标明用途。需要可见说明时将文字放入标签。轨道为 40×20px，圆点直径为 12px。状态过渡为 167ms，悬停和按下反馈为 83ms。整组设置停用时使用 `.is-off`，开关仍可用。
- 单行文本类输入框可用上下方向键切换焦点。最后一项按向下键进入主操作按钮。多行文本、下拉框、数字与日期时间控件及带候选列表的输入框保留原有键盘行为。
- 搜索框按 Esc 清空内容并触发 `input` 事件。弹窗中输入框有焦点时，Esc 保留弹窗。其他情况下 Esc 执行取消。

### 账号选择弹窗

面板和活动后台共用[账号选择组件](architecture.md#账号选择)。候选区域高度固定，按宽度调整列数，候选项显示头像及显示名。单选模式替换当前选择，多选模式切换各项状态。

只有 [完成] 提交选择。取消、Esc、关闭按钮均舍弃未提交的更改。点击遮罩不关闭弹窗。单选模式下，无选中项时 [完成] 不可用。

### 确认与提权

普通操作直接执行，需要确认的操作使用 `confirmHighRisk()`。无需提权的确认传入 `{noSudo: true}`。需要提权时，尚未启用 sudo 模式的密码提示本身即为确认。适用权限和行为见 [sudo 模式](../usage/sudo.md)。

确认弹窗可叠加在详情上。取消确认时返回详情。归档、取消归档及彻底删除成功后关闭相关详情。转移拥有者、下载和回收资源等操作保留详情。允许点击遮罩退出的弹窗由 `OVERLAY_OUTSIDE_CLOSE` 维护。

## 反馈

- `PX.toast()` 用于短时操作结果，可附一个后续操作。动作按钮与关闭按钮同行，保持提示高度。
- 需要后续处理或查阅的信息使用通知中心。收起时采用位移、透明度和可见性控制，避免隐藏属性中断动画。通知中心层级低于顶栏。
- 紧急通知使用独立弹窗，提供 [已读] 与 [关闭]。Esc 等同关闭，点击遮罩不结束提示。
- 服务版本变化时，安全情况下自动刷新。有未提交输入或打开的弹窗时显示 `.update-bar`，由使用者选择刷新。

## 措辞

使用简洁书面语。页面副标题用一句话说明页面用途，通常不加句号。按钮采用动词或动宾短语。状态词、角色和功能名称以[术语表](../reference/glossary.md)为准。

状态标记邻接标题，原因置于可悬停或点击查看的提示中。标记与提示保持卡片高度。界面时间按相应页面的时区规则显示。审计说明的结构见[项目架构](architecture.md#审计)。

## 侧栏与抽屉

侧栏项按账号角色过滤。没有可见项目的分组连同分隔线隐藏。侧栏作为一个 Tab 焦点区域，用上下方向键在可见项间移动，Home 和 End 分别转至首项和末项。

侧栏与会话抽屉共用遮罩，对应宽度为 `min(86vw, 320px)`，过渡时间为 220ms。遮罩、Esc、关闭按钮或路由切换均可收起抽屉。待所有共用抽屉收起后再移除遮罩。

## 滚动条与附加操作

全局滚动条样式由 `:root` 的 `scrollbar-width`、`scrollbar-color` 及 WebKit 兼容样式提供。

与主操作同类的低频操作可置于主按钮右侧的 [更多] 菜单。两按钮同高，接合处不留缝，图标按钮仅保留外侧圆角。菜单复用 `.card-menu`，点击外部或按 Esc 收起。

## 打印页

`/print` 使用独立的纸张和工具栏布局。`.sheet-page` 为 210×296.8mm，内边距为上下 14mm、左右 12mm。`@page` 的边距设为 0。页面提前分页并显示页码。纸张采用白底黑字，工具栏使用 `.no-print`，标题和二维码等附加元素默认关闭。

## 布局断点

| 窗口宽度 | 布局 |
| --- | --- |
| 大于 1100px | 侧栏同时显示图标与文字 |
| 761–1100px | 侧栏显示图标，分组展开显示子项 |
| 760px 及以下 | 通过顶栏打开侧栏，内容区改为单列，表格可横向滚动，日期与时刻采用原生选择器 |

新页面沿用同一结构适配各断点。验证返回键、卡片间距、表格列宽、表单焦点、加载状态和窄布局，并检查新增的 `data-*` 属性是否与现有委托选择器冲突。
