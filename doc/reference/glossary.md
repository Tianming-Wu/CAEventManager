# 术语表 - 界面、文档与代码共用的词

界面上、文档里、代码注释里都用这套词。改一处的说法就要改三处，所以先在这里定下来。

## 主体

| 词 | 指什么 | 不用 |
| --- | --- | --- |
| 活动 | 一场要用到签到、任务、奖票与抽奖的现场 | 场次、event（界面上） |
| 名单 | 可以反复使用的一批人（社团成员、某次比赛选手） | 名册、名簿 |
| 报名 | 一条公开链接，报名成功的人直接写进某份名单 | 招募、登记表 |
| 人员 | 平台级的人；同一个人在多份名单里是同一条记录 | 学生、用户（指人时） |
| 成员 | 某个活动里的席位：负责人 / 成员，可以「已移出」 | 参与者（那是另一回事） |
| 预设 | 一份存下来的活动配置（模块 + 参数 + 建议名称） | 模板（模板是模块之上的旧说法） |
| 模块 | 一种活动形式的能力边界（声明参数与页面） | 插件 |
| 账号 | 登录面板的身份 | 用户（界面上叫账号） |
| 短链 | 平台生成的临时跳转地址，形如 `/s/AB3D7KM`，属于活动的平台资产 | 短网址、外链 |
| 提权操作 | 要进 sudo 才能做、会动别人数据或不可逆的动作（强制归档、删除已归档活动、改角色……） | 越权操作（那听起来像"不该做"） |

## 角色

| 词 | 能力 |
| --- | --- |
| 站长 | 唯一。全部权限，含服务器管理与审计日志 |
| 超级管理员 | 账号、活动、审批、外部资源 |
| 管理员 | 自己的活动、名单、报名、助手 |

活动里的席位另有三个：**负责人**（可邀请与移出成员）、**成员**、**已移出**。

## 状态词

| 场景 | 取值 |
| --- | --- |
| 活动 | 未开始 / 进行中 / 已结束 |
| 报名 | 未开始 / 进行中 / 已结束 / 已满 / 已禁用 |
| 名额 | 不限 / 剩余 N |
| 名单成员 | 在册 / 已退出 |
| 活动成员 | 待确认 / 在册 / 已移出 |
| 账号 | 待审核 / 正常 / 已停用 / 已拒绝 / 已封禁 |
| 名单可见性 | 私有 / 公开 / 组织公开 |

## 现场

| 词 | 指什么 |
| --- | --- |
| 签到 | 到场登记；必须扫大屏二维码，学号与姓名都要对上名单 |
| 任务一 / 任务二 | 任务链的两环：签到 → 任务一 → 任务二 |
| 越序 | 前一环没完成就标后一环；解锁修改后允许，写进日志 |
| 奖票 / 票号 | 抽奖用的凭证；按顺序发号，与池子大小解耦 |
| 保底票 | 每个人必得的那部分票 |
| 抽奖池 | 可抽的票的集合，按池子模式计算 |
| 逐个 / 一次抽完 | 奖品的抽取节奏 |
| 公示页 | 只读的对外页面 |
| 大屏 | 投影页 |
| 操作台 | 活动后台里现场用的主页面 |

## 文档与代码里的固定说法

- 中文界面用「创建」，不用「申请」；「申请」只留给权限申请
- 按钮用动词：保存 / 创建 / 导入 / 移出 / 授予写入权限 / 清除密钥
- 空状态：还没有…；没有匹配的…
- 分页按钮：再显示 N 条
