# 短链 - 临时跳转，属于活动的平台资产

短链是一条形如 `https://…/s/AB3D7KM` 的地址，打开它会被转到某个活动里的某一页。
它由平台生成与回收，**只作临时用途**：平台不保证长期有效，随时可能被删除、过期或用尽次数。
需要长期可用的地方（报名表二维码、公告里的链接）必须直接用活动地址。

## 谁能生成

生成入口不在面板里，而是由**模块申请的**：活动所用的模块在 `module.json` 里申请了
`features.shortlink` 之后，活动后台的「活动设置」里才出现「短链」卡片。

卡片上三样东西：

| 项 | 说明 |
| --- | --- |
| 指向 | 模块声明的目标，例如 大屏、签到页、公示页 |
| 有效期 | 分钟数；留空表示不设过期，最多 30 天 |
| 最多访问次数 | 留空表示不限 |

底部是这场活动现有的短链：短链号、指向、剩余有效期、已访问次数与上限，右侧 [删除]。

## 规矩

- **一个活动能同时持有多条**，上限是平台的静态设置（默认 5 条，改服务器上的配置文件并重启才生效）。
  超限时生成请求会被拒绝并说明当前条数
- **删除即消失**：短链不做软删除，也没有撤销入口
- **活动归档时，平台把它的短链全部销毁**
- 短链不写审计：它只是一次跳转，没有复盘价值

## 超管

超级管理员能看到每个活动还持有多少条短链，并能删除任何活动的短链——这是替别人做破坏性改动，
**要先进入 sudo 模式**；已经在 sudo 模式时还要再确认一次。

## 用例

现场那台投屏电脑敲不进长地址时，生成一条指向「大屏」的短链，把 `/s/…` 那七个字符输进去即可。
用不上就删掉。
