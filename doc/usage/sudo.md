# sudo 模式 - 提权操作的密码认证

## 启用与退出

首次执行提权操作时，须输入当前账号的密码。认证通过后，平台执行该操作并启用 sudo 模式。

启用后，顶栏左侧显示盾形图标。点击图标可查看剩余时间或退出 sudo 模式。

sudo 模式有效期为 10 分钟。在有效期内执行提权操作时，确认操作即可。执行操作不会延长有效期。刷新页面会保留当前状态，退出登录会结束 sudo 模式。

## 适用操作

提权操作包括彻底删除已归档的活动、名单或报名，以及代其他账号归档对象等。各管理页面的操作权限参见[平台管理页](platform-pages.md)。
