# 平台管理页 - 用户管理、模块管理与展示屏幕

「用户管理」、「活动管理」、「名单管理」和「组织管理」功能只对超级管理员及以上开放。

站长另有审计日志与服务器管理，见 [server.md](server.md)，**模块管理页面只对站长可见**。

## 用户管理

侧栏「用户管理」。

点击页面右上角的 [新建账号]，填写登录名和显示名。站长可选择账号角色。系统生成临时密码，参见[临时密码](#临时密码)。

站长可点击 [新建账号] 左侧的 [导入账号]，批量创建账号。参见[导入账号](account-import.md)。

内容区一张账号表：列为 登录名 / 显示名 / 角色 / 状态 / 最近登录 / 操作；
表头右侧是搜索框，列表底部提供分页按钮。列表上方写着「共 N 个账号」；设置账号上限后，列表同时显示上限。达到上限时显示「已满」，并停止接收新注册申请。

点击操作列的 [管理] 查看可用操作，包括封禁或停用、重置密码和 [调整存档配额]。站长可设置角色。注册审核参见[注册申请](approval.md#注册申请)。

### 临时密码

在「用户管理」中新建、导入或重置密码的账号使用临时密码。首次使用临时密码登录时，须在「重设密码」页面设置新密码。

新建或重置时，系统生成的临时密码仅显示一次。可在账号弹窗点击 [复制]。批量导入时参见[导入账号](account-import.md)。

### 重置密码

在「用户管理」打开账号详情，点击 [重置密码] 并确认密码。系统生成新的临时密码，原登录会话及 API 令牌失效。

超级管理员可重置管理员的密码。站长的密码由站长在「账户信息」中修改。

### 彻底删除账号

它**只对已停用的账号出现**，而且需要满足特定条件可用：

| 账号状态 | 弹窗 |
| --- | --- |
| 正常 / 待审核 / 已封禁 | 「彻底删除」不可见 |
| 已停用，尚未达到规定期限 | 有，灰显并无法点击；鼠标悬停显示剩余时间 |
| 停用期限已满，但仍拥有未归档的活动、名单或报名 | 有，灰显并无法点击；鼠标悬停提示原因 |
| 停用期限已满，且无未归档的活动、名单或报名 | 可用，须进入 [sudo 模式](sudo.md) |

随账号删除的数据：会话、API 令牌、助手存档、头像、活动席位、站内通知、草稿、预设收藏。
**审计日志不会被删除**。

已归档的活动不会影响账号删除。名单与报名可以使用「名单管理」功能转移所有权，或者删除。

## 活动管理

侧栏「活动管理」。

内容区两张表：**当前活动**与**归档的活动**，两张表列一致：活动 / 活动号 / 负责人 /
时间（当前活动是创建时间，归档则是归档时间）/ token / 操作。活动名称旁的「不可用」标记可悬停或点击查看原因。
**首列的活动名可以点击**，和「详情」按钮一致。详情内会显示活动的高权限操作：

| 动作 | 当前活动 | 已归档 |
| --- | --- | --- |
| 打开活动设置 ↗ | ✓ | — |
| 下载数据 / 下载完整数据 | ✓ | ✓（含归档包） |
| 转移负责人 | ✓ | — |
| 回收站内资源 | ✓ | — |
| 强制归档 | ✓ | — |
| 取消归档 | — | ✓ |
| 彻底删除 | — | ✓ |

除了「打开活动设置 ↗」「转移负责人」（负责人自己做时不需要提权），其余需要 sudo。
见 [sudo.md](sudo.md) 了解 sudo 模式。

原负责人账号已删除时，执行 [取消归档] 须先指定新负责人。

## 名单管理

侧栏「名单管理」。

页面分别列出名单与报名。点击名称打开详情及可用操作。

使用第一张卡片顶部的 [当前] 和 [已归档] 切换列表。「已归档」显示归档时间。

| 表 | 列 |
| --- | --- |
| 名单 | 名单 / 拥有者 / 可见性 / 人数 / 更新时间 / 操作 |
| 报名 | 报名 / 拥有者 / 状态 / 已报名 / 更新时间 / 操作 |

详情弹窗内动作按对象类型决定：

| 类型 | 动作 |
| --- | --- |
| 当前 | 打开 ↗ / 转移拥有者 / 归档 |
| 已归档 | 取消归档 / 彻底删除 |

- **归档**：从拥有者的列表移除名单或报名。
- **取消归档**：恢复至拥有者的列表。
- **彻底删除**：永久移除已归档的对象。
- **转移拥有者**：选择新拥有者。原拥有者保留写入权限。

上述动作都需要 sudo 模式。

## 组织管理

侧栏「组织管理」。内容区一张组织表：列为 名称 / 标识 / 成员 / 我的身份 / 状态 / 操作，
表头右侧可按名称或标识搜索。右上角 [创建组织] 进入「组织管理 › 创建组织」页面。

组织记录归属关系，组织内的身份不带来平台权限。归档把成员关系折进组织那一行存放，
恢复时展开；[彻底删除] 只对已归档的组织出现，只对站长可见，须 sudo 模式。

参见[组织](orgs.md)。

## 模块管理

站长可在侧栏打开「模块管理」。内容区一张表：模块 / 版本 /
作者 / 引用计数 / 操作，右上角 [导入模块]，最右一列是 [卸载]（适用于导入的模块）与 [停用] / [启用]。
「引用计数」表示使用该模块的活动数量。

### 导入

[导入模块] 打开文件选择窗口。支持 zip 格式。
压缩包内需要包含模块目录（`module.json` 在最外层，或者整个目录一起打包）。

- 解析完会列出模块清单：模块名、标识、版本、作者、体积，以及它申请的能力。
  如果模块申请了高危能力，会突出显示「模块申请以下高危权限」。
- 平台自带的模块不可卸载，也不能用同名的模块覆盖。
- 暂时不支持模块更新。可以先卸载旧模块再导入新模块，但请确认数据格式兼容。这是模块实现细节，平台无法保证。

### 停用与启用

停用与启用需要站长进入 sudo 模式操作。

- 停用之后，使用这个模块的活动立刻不可用：正在运行的活动会被停用。
  说明页写着「此活动不可用 / 此活动必需的资源已被管理员停用」。
  「我的活动」的卡片在标题右边多一枚红色「不可用」胶囊，悬停或点击显示原因
- 活动数据会被冻结。停用的模块也不再出现在创建活动的列表里，它的预设一并不可用
- 启用之后活动立刻恢复，刷新页面即可。
- 模块异常时可能自动停用。平台会发送通知并记录到审计日志。故障排除后，可点击 [启用] 恢复。

### 高危权限

有的模块会申请平台保留的高危能力（例如不受限制的短链跳转）。这类模块在
名称右侧显示红色「高危」胶囊，悬停或点击可以看到申请的高危权限列表。

高危权限**申请即生效**，平台没有二次授权机制。如果模块来源不可信，请谨慎使用。

高危权限调用会在审计日志留下记录。

## 展示屏幕

侧栏「外部资源 › 展示屏幕」。页面右上角 [导入]；内容区三块：可用的屏幕、导入说明、引用方式。

- 「可用的屏幕」列出内置与导入的展示屏幕，各自有标识与体积
- 「导入说明」写着导入要求：包内要有 `screen.html`，只收样式表、脚本与图片，压缩包 2 MB 以内、
  解压大小 8 MB 以内
- 活动用哪一份屏幕，在活动后台的「活动设置」里选

## 使用文档

点击侧栏「使用文档」，在新标签页打开文档查看器。目录分为「使用说明」「参考」和模块说明。窄布局下可点击顶栏左侧的 [目录] 展开目录。

顶栏右侧可返回面板或切换浅色与深色主题。可通过目录、正文链接或章节标题跳转，并复制浏览器地址以分享当前文档或章节。
