# 界面描述写法 - 位置词、按钮与图标

使用者文档按这一套词描述界面。助手照这些词回答，用户才找得到地方。

## 位置词

| 词 | 指什么 |
| --- | --- |
| 顶栏 | 面板最上面那一条：产品名、版本、机器占用、通知铃铛 |
| 侧栏 | 左边那一列导航 |
| 页面标题 | 内容区最上方的大字，例如「我的名单」 |
| 页面副标题 | 标题下面那一行小字，写状态或说明 |
| 页面右上角 | 与标题同一行的右侧，主操作都在这里 |
| 内容区 | 标题下方放卡片的地方 |
| 卡片 | 一块带标题栏的内容；卡片标题栏右侧放搜索框与按钮 |
| 表格 | 卡片里的表；第一列是对象名，最右一列是操作 |
| 页签 | 活动后台里那一排页，例如 操作台 / 名单 / 日志 |
| 抽屉 | 从左边滑出的一层，例如会话列表 |
| 弹窗 | 盖在页面上的一小块，例如「模型设置」 |
| 输入框 | 可以打字的地方；旁边的按钮跟在后面写 |

## 布局

界面按**窗口宽度**分三档，与设备类型无关（平板横放与笔记本一样算宽屏）：

| 窗口宽度 | 侧栏 |
| --- | --- |
| 大于 1100px | 侧栏带文字 |
| 761～1100px | 侧栏只留图标，文字与分组子项收进抽屉 |
| 760px 及以下 | 侧栏整个收起，顶栏左侧出现 [打开导航（三条横线图标）] |

窄屏（760px 及以下）另有几处不同：内容区单列、表格横向滚动（首列与操作列贴边）、
日期与时刻改用系统选择器、运维助手的输入框一开始就是两行。

写文档时，位置与布局有关的要注明是哪一档，例如：
`宽屏下在侧栏；窄屏下在顶栏左侧的 [打开导航（三条横线图标）] 里`。

## 按钮

- 有文字的按钮写原文，用方括号括起来：[保存]、[导出 Excel]、[移出]
- 只有图标的按钮，在名称后面补图标的样子：[模型设置（齿轮图标）]、[导出这段对话（下载图标）]、
  [新建会话（对话气泡加号图标）]、[全屏编辑（四角图标）]、[更多格式（三个点图标）]、
  [通知（铃铛图标）]、[打开导航（三条横线图标）]、[关闭（叉号图标）]、[返回（左箭头图标）]
- 图标只用最朴素的词：齿轮、铃铛、下载、上传、加号、叉号、三个点、左箭头、三条横线、四角、对话气泡
- 写清在哪个区域：`页面右上角的 [模型设置（齿轮图标）]`、`表格最右一列的 [移出]`、
  `输入框右侧的 [发送]`

## 状态与开关

- 开关写「打开 / 关闭」：`卡片标题栏右侧的 [启用] 开关`
- 状态写原文：`状态列的「已退出」`、`标题旁的「待审核」`
- 按钮可用、不可用也要写：`[保存] 在拥有写入权限时才出现`

## 示例

> 报名详情页的页面右上角依次是 [保存设置]、[下载二维码]、[导出报名表]、[导出 Excel]、
> [打印报名表]；[下载二维码] 右边是 [更多格式（三个点图标）]，里面有另外两种图片格式。
