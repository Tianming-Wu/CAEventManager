# 奖票抽奖 - 现场说明

活动后台提供「操作台」「名单」「奖票」「抽奖」和「奖票设置」。

## 模块信息

| 项目 | 内容 |
| --- | --- |
| 名称 | 奖票抽奖 |
| 模块 ID | `nwuca.lottery` |
| 提供方式 | 内置 |

## 签到

参会人员扫描大屏上的签到二维码，填写学号和姓名。两项均与名单匹配时，签到成功。

## 操作台

在操作台查看人员并标记签到和任务状态。

- **搜索**：搜索框支持姓名、拼音全拼、拼音首字母及学号片段。
- **混合搜索**：以空格分隔多个条件，结果须同时满足各条件：
  - 拼音按**逐字音节**匹配，可输入音节前缀或省略部分音节：
    周子墨（zhou zi mo）可通过 `zhouzimo`、`zzm`、`zhouzm`、`zhoum`、`zm` 检索
  - `#` 开头是标签条件，点击搜索框内的提示可补全：`#w`/`#工作人员`（工作人员）、
    `#v`/`#志愿者`、`#p`/`#参加人员`、`#已签到`、`#未签到`、`#已完成`、`#未完成`、
    `#有票`、`#无票`；在标签名称前加 `-` 可排除该标签，例如 `#-工作人员`
  - 例如 `#w #未签到` 用于查找未签到的工作人员
- **完成任务**：参与者依次完成 签到 → 任务一 → 任务二。前置环节未完成时，页面将提示缺少的环节
- **解锁修改**：启用后可越序标记，操作日志会注明未完成的前置环节。30 秒无操作后自动锁定。
- **奖票**：按奖票池规则发放，票号按发放顺序分配

## 奖票池

| 模式 | 取值 |
| --- | --- |
| 自动 | 到场人数 × 3 + 常数（默认 20） |
| 固定 | 指定张数 |
| 表达式 | 例如 `signed_in * 3 + 20` |

表达式可使用四则运算、`min`、`max`、`round`、`abs` 和 `int`。可用变量为 `signed_in`、`present`、`participants`、`staff_present`、`tasks_done`、`guaranteed`、`bonus_constant` 和 `pool_size`。奖票池可调整，调整后的容量须大于或等于已发放的奖票数量。

## 抽奖

各奖品可选择「逐个」或「一次抽完」。前者每次抽取一个名额，后者一次抽取剩余名额。大屏同步展示抽奖结果。

按票抽取的候选范围为已发放且符合资格的奖票。可在「奖票设置」配置同一奖品或不同奖品的中奖限制。按人抽取的奖品以到场人员为候选，适用的限制由该奖品的设置决定。候选数量不足时，页面会说明原因。

作废抽奖记录后，仍符合抽奖条件的人员可再次参与。

## 名单页

- 支持 CSV / TSV 导入，有表头自动识别，按学号增量更新，重复导入不留重复记录
- 区分参加人员 / 工作人员 / 志愿者：工作人员与志愿者仅记录到场，仍可参与特等奖抽取
- 活动结束后导出 ZIP：`01-汇总`、`02-名单`、`03-奖票明细`、`04-抽奖记录`、`05-中奖汇总`
  五张 CSV 与 `06-操作日志.log`

## 预设

模块提供小型沙龙预设。也可在「我的活动」中打开活动卡片菜单，点击 [保存为预设]。参见[预设](../../../doc/usage/presets.md)。
