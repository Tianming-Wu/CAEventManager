# 导出与打印 - 表格与纸张

两种拿出去的办法：导出成表格接着用，或者印成纸带到现场。

## 导出

| 在哪 | 按钮 | 得到 |
| --- | --- | --- |
| 名单详情 | 导出 CSV | 一份 CSV |
| 名单详情 | 导出 Excel | 一份 xlsx |
| 报名详情 | 导出报名表 | 一份 CSV |
| 报名详情 | 导出 Excel | 一份 xlsx |

- **两种都只有表头与数据行**：不加标题、不加说明、不加合计。表格是拿来接着用的，不是拿来当通知的
- CSV 带 BOM，Excel 双击就能打开
- xlsx 里全是文本单元格，学号不会变成数字、前导零不会掉
- xlsx 的读写认得文本、数字与布尔值，空行跳过，合并单元格只取左上角；公式、图表、多个工作表不处理
- 往名单里导入 xlsx 见 [rosters.md](rosters.md)，接口形式见
  [../reference/api-tables.md](../reference/api-tables.md)

## 打印名单

名单详情右上角的「打印名单」，另开一张纸。一张简单的表：序号、学号、姓名、院系、班级；
有人分组就多一列分组，有已退出的人就多一列状态。

- 每页左下角标「第 N / M 页」，换页时表头重复
- 标题是勾选项，默认不加
- 屏幕上看到的就是印出来的样子：每页按 A4 的可打印区切成一块

## 打印报名表

报名详情右上角的「打印报名表」。默认就是**已报名单**：学号、姓名、院系、班级与自定义字段。

- 每页左下角标「第 N / M 页」
- 标题与二维码各有一个勾选框，默认都不加
- 「空白表」留在切换里备选，行数可调；实际更常用的是在线报名
- 打印时工具栏自动消失，纸永远是白底黑字，不受界面设置影响

谁能看这份报名，谁才能打印它的报名表：打印页读的是面板自己的接口。
