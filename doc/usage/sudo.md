# sudo 模式 - 敏感操作认证

## 机制

平台的敏感操作需要一次密码认证。这种认证称作 sudo 模式。

输入密码确认之后，触发 sudo 模式的操作会被立刻执行，而不会再弹出二次确认。

启用 sudo 模式时，顶栏左端会出现出现盾形标记。标记可以点击，会弹窗显示剩余时间，并提供手动退出按钮。

sudo 模式的持续时间为 10 分钟。持续时间期间，所有的敏感操作都降级为二次确认，而不需要再次输入密码。
用户仍然会看到一样的安全警告，但只需要点击确认。持续时间不会在敏感操作执行时刷新。

sudo 模式作用于本地登录会话。退出登录会退出 sudo 模式。sudo 模式不会跨设备、跨浏览器启用。
刷新页面不会退出 sudo 模式。

## 内容

敏感操作在本平台可以理解为 “破坏性操作” 和 “高权限操作”。

超级管理员或站长在执行会永久导致数据丢失、无法找回的操作，例如删除账号、彻底删除已经归档的活动等，
需要进入 sudo 模式操作。

超级管理员或站长在执行会影响其他用户正常使用的操作，例如归档其他用户创建的活动、删除其他用户的信息等，
也需要进入 sudo 模式操作。

普通管理员不需要 sudo 模式，因为权限本身无法执行足够敏感的操作。

多数自己进行的操作，或可恢复的操作，例如归档自己创建的活动、归档自己创建的名单等，仅需要二次确认，不需要进入 sudo 模式。
